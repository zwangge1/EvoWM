# v3 事后诊断：零模型里给出习性为什么让预测变差（2026-10-14，不参与判定）

脚本 `scripts/exploratory/diag_e1_null_v3.py`，原始结果在服务器 `outputs/recovery_v3/diag_e1_null/`（diag.json）。
只用 v3 已训练的模型重新评估，不重新训练。新科上绝对跗跖的数字与 v3 报告逐一相同，核对通过。

## 结论

1. **主因是体重通路。** 给出习性后，体重预测在新科上变差：8 组模型（零模型、效应 × 种子 1、2、5、6）全部为负，-0.0039 到 -0.0083；同样的模型在训练科上全部为正，+0.0057 到 +0.0070。模型用习性信息去猜目标种的体重，这些猜法只在训练科里成立。腿长随体重缩放（各折异速斜率 0.31 到 0.37），体重猜错就连带把绝对腿长猜错。
2. **扣除体重后，E1 变得干净。** 相对跗跖 = 跗跖 − b × 体重。零模型的代价从 -0.0012 到 -0.0028 缩小到 -0.0004 到 -0.0006；效应情景四个种子全部显著为正：全部相邻对 +0.0034 到 +0.0044（区间下限 +0.0022 到 +0.0032），习性变化的物种对 +0.0068 到 +0.0081。
3. **是过拟合。** 零模型里，习性在训练科上"有帮助"（跗跖 +0.0020 到 +0.0022，体重 +0.0063 到 +0.0070），在新科上有害。
4. **不集中在少数习性。** 体重的代价在各类习性上都有，包括科数最多的栖树（113 个科）；按运动方式算的平均体重偏移，与训练科、新科残差的相关都不稳定（0.18 到 0.92）。代价主要来自模型用整套生态描述（食性、栖息地、觅食层等）逐种调整体重，而不是某几类习性的系统偏移。
5. **效应情景按习性拆开**，相对跗跖的增益以涉水（+0.029 到 +0.036）和空中（+0.012 到 +0.017）最大，与模拟设定的偏移大小（涉水 +0.20，空中 -0.15）一致。

## 含义

E1 的问题不在概念，而在用绝对腿长度量：绝对腿长把模型对体重的猜测也算了进去。E1 应改用相对腿长，与 E2 的处理一致，也就是旧工作里 log-log 异速的思路。种子 5、6 已经在相对腿长下看过，之后的正式检验要换新种子。

增益 = 无习性 RMSE − 有习性 RMSE（log10），为负表示给出习性后预测变差；95% 置信区间按科自助重抽样 1,000 次。"新科"是各折留出的科（与 v3 评估相同，跗跖绝对值的一列应与 v3 报告一致）；"训练科"是各折训练用的科。相对跗跖 = 跗跖 − b × 体重，b 为各折训练物种上的异速斜率。
