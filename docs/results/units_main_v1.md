- **第 0 阶段通过**：G1-L2、G2-L2、G-L1 都通过；G3-L2 也通过，H4 为确认性检验。E2 的判定方式为零模型阈值 T = 0.0106（零模型 12 个对比中，按科区间不含 0 的有 5 个，按目 3 个）。

## 4. 解读

1. 在类群一级，一种明确运动方式换成另一种时，习性变化能预测新类群的典型相对腿长（H3），方向与已知规律一致（H4）。第二层 6 类反事实的方向与 PGLS 全部一致，第一层有 2 类（潜水、水面）不一致。
2. 增益随目标类群变大而变大（S4）：只有 1 种时与零模型下的水平相当（−0.0023，零模型 −0.0026、−0.0018），超过 16 种时 +0.0154。模拟效应情景里也有类似的梯度：成员平均的噪声更小、类群在新体制里的时间更长，都会产生它。可检出的信号集中在成规模的类群转变上，这一点不单独说明机制。
3. 运动方式不变时，细习性的变化没有检出作用（S2）。
4. 运动方式转变时体重、HWI 也跟着变：第二层两者的增益为正，模拟里同一读数为负。
5. 第三层（描述）：进入空中，相对腿更短、体重更轻、HWI 更高，三项都超出模拟参照；进入水中，相对跗跖 +0.021 约为零模型偏移的两倍，体重、HWI 在模拟参照范围内或附近，不作解读。
6. 分层本身：联合训练不改变第一层（S1）；第二层预测单位平均腿长的误差大于第一层（S5，模拟里也是）；第二层世界模型与线性基线没有差别（S3），第三层世界模型好于只用栖境类别的线性基线，但两者输入不同。分层的作用是让"运动方式转变决定腿的方向"能在类群一级检验（预注册第 8 节）。

## 5. 注意事项

- 第 0 阶段零模型下 H3 读数偏负（种子 13 为 −0.0027，区间不含 0），H3 偏保守。
- 全部转变（含泛化）的读数区间含 0。只看不涉及泛化的转变，是在开发检查（`docs/results/dev_units_v1.md`）里、看任何真实数据之前定的。
- 反事实对比的大小只有真值偏移的 3% 到 36%（第 0 阶段），只解释方向与排序。
- 零模型阈值只来自 2 个零模型实现（10 次运行），是粗略的参照。
- 第三层只有部分校准：相对跗跖读数在效应情景两个种子中一个恢复（种子 13 区间含 0）；体重、HWI 只有零效应下的参照，模拟里它们的反事实也有偏移（水中体重 +0.010 到 +0.032，空中体重 −0.002 到 −0.043）。
- H3 用扣除体型的相对跗跖；第二层体重增益为正，说明真实鸟类改变运动方式时体型也在变。
