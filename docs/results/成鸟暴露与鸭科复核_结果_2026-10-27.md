# 成鸟暴露说与鸭科复核：结果（2026-10-27）

> 设计《成鸟暴露与鸭科复核_设计_2026-10-27》，判据先定。一句话：**鸭科独立复核了"Allen 定律只落在跗跖骨"；成鸟暴露（露天觅食比例）在统计上吸收了发育方式的差别，并且在雀形目内部给出了一条连续的梯度。** 故事从"发育方式"换成"成年后腿是否露天"。

## 符号与术语

- $X$：成鸟暴露代理，EltonTraits 的地面 + 水面附近 + 水下觅食比例之和（0 到 1）。
- 系数：温度每升高 10 °C，$\log_{10}$ 长度的变化；0.0043 对应 1%；方括号为 95% 区间。
- P 组：早成鸟。$r = \log_{10}(\text{跗跖骨}/\text{股骨})$。

## 1. 三个检验

**A　早成鸟内部，X 是否预测斜率：无法检验。** P 组 813 种里 X 的均值 0.92，四分位 1.00 到 1.00，几乎全是露天觅食，没有变异可用。按预设规则记"反对"（$T \times X$ 区间含 0），实质是没有功效，不作为证据。

**B　全部非雀形目（3,230 种），成鸟暴露能否吸收发育方式：能。** 只放发育方式时 $T \times$ 暴露组 = +0.0083 [+0.0025, +0.0140]；加入 $T \times X$ 后降到 +0.0034 [−0.0033, +0.0102]，而 $T \times X$ = +0.0092 [+0.0015, +0.0169]。成鸟暴露说优先。

**C　鸭科 90 种（Watanabe 2017，独立于 Eliason）：复核通过。** 股骨 +0.0029 [−0.0058, +0.0117]，胫跗骨 +0.0073 [−0.0022, +0.0169]，**跗跖骨 +0.0137 [+0.0010, +0.0265]**，**$r$ +0.0107 [+0.0033, +0.0181]**。第三份独立骨骼数据，同样是只有跗跖骨动。

## 2. 探索：雀形目内部的梯度

雀形目 4,882 种：$T$（$X = 0$，纯树栖或空中）= −0.0076 [−0.0101, −0.0052]；$T \times X$ = +0.0071 [+0.0031, +0.0112]；$X = 1$（完全地面觅食）时斜率 −0.0005，接近 0。越是在地面活动的雀形目，腿越不反向。

## 3. 合起来的图

把三周的结果按"成年后腿露天的程度"排一排：

| 类群 | 腿露天程度 | 跗跖对温度（每 10 °C） | 分段 |
|---|---|---|---|
| 早成的地栖与水生鸟（雁鸭、鸡形、鸻鹬、鹤、秧鸡） | 整天站在露天 | +1.5% 到 +3.8%（外测、Eliason 骨、鸭科骨三份数据） | 只有跗跖骨动，股骨不动（Eliason、鸭科两份独立复核） |
| 半早成、半晚成（鸥、猛禽、鹭、鹳） | 中等 | +0.5% 到 +1.1% | 跗跖骨偏正，未达显著 |
| 晚成非雀形目（鹦鹉、鸽、雨燕、啄木鸟） | 多在树上或空中 | 0 | 无 |
| 地面觅食的雀形目 | 中等 | 约 0 | |
| 树栖与空中的雀形目 | 腿缩在腹羽里 | −0.8%（反向） | 比例反向（Skelevision、Eliason 两份数据） |

- 这是一条连续的梯度，不是两组。发育方式之所以看起来有效，是因为它和成年后的腿露天程度高度重合；一旦把露天程度放进模型，发育方式的差别就消失了（B）。
- 机制与 10-21 分段假说的生理前提一致：跗跖骨是裸露的散热面，温度选择作用在它上面，而且只在腿确实露在环境里的类群中起作用。树栖鸟把腿缩进羽毛，腿不是散热面，热带树栖鸟腿反而略短，原因另议（树栖生活的力学或别的热调节策略）。
- 翅骨的 Allen 定律落在另一些类群上（半晚成与雀形目），和腿的分布互补，提示不同类群把"散热窗口"放在不同的附肢上。这一条是探索性的。

## 4. 论文可以主张的与还缺的

可主张：鸟腿的 Allen 定律是分段的、由成年后腿的暴露程度决定的；三份独立骨骼数据复核分段；外测跗跖 9,000 种给出跨类群梯度；雀形目反向并在地面觅食者中减弱。

还缺一个预注册的独立确认：**种内层面**。UMMZ 标本级数据（85 种雀形目、1,058 件）里，地面觅食比例高的物种，种内跗跖骨对采集点温度的斜率应该比树栖物种更正。这是和跨物种完全不同层面的数据，判据可以先写定再跑，一天。通过的话，论文的证据链就从跨物种、骨长、种内三个层面闭合。
