# 迁徙分层的稳健性（结果，2026-10-30）

> 设计《迁徙分层_稳健性_设计_2026-10-30》，判据先定。一句话：**主张成立，而且对文章有利。** 三个分析在三个迁徙层里全部同号，留鸟层内全部显著，并且效应在留鸟中最强。留鸟的分布质心温度最能代表它生活的温度，迁徙鸟的质心混合了繁殖地与越冬地，效应在迁徙层变弱正是温度变量被稀释时的预期。

## 符号与术语

迁徙等级 0 留鸟、0.5 部分迁徙、1 完全迁徙（AVONET）。系数为每升高 10 °C 的 $\log_{10}$ 变化，0.0043 对应 1%，方括号为 95% 区间。各层内去掉迁徙协变量，其余同原分析。

## 结果

| 分析 | 全部 | 留鸟 | 部分迁徙 | 完全迁徙 |
|---|---|---|---|---|
| 非雀形目，发育方式之差 | +0.0091 [+0.0037, +0.0146]（3,574） | **+0.0156 [+0.0073, +0.0240]**（2,770） | +0.0084 [−0.0072, +0.0240]（444） | +0.0025 [−0.0107, +0.0158]（360） |
| S_all 两轴，暴露轴 $f$ | +0.0078 [+0.0038, +0.0118]（8,112） | **+0.0077 [+0.0020, +0.0133]**（6,507） | +0.0098 [−0.0032, +0.0228]（840） | +0.0035 [−0.0073, +0.0143]（765） |
| S_all 两轴，体型轴 $d$ | +0.0037 [+0.0014, +0.0059] | **+0.0041 [+0.0006, +0.0075]** | +0.0077 [+0.0018, +0.0136] | −0.0004 [−0.0063, +0.0054] |
| 留鸟，只有暴露轴，非雀形目 | | **+0.0107 [+0.0018, +0.0196]**（2,482） | | |
| 留鸟，只有暴露轴，雀形目 | | **+0.0086 [+0.0027, +0.0146]**（4,025） | | |

- 判据：三层同号（发育方式之差与暴露轴），留鸟层区间不含 0，**主张成立**。体型轴在完全迁徙层为 −0.0004，与全样本异号但区间含 0，不构成反证。
- 发育方式之差在留鸟中为 +0.0156，比全样本大七成；迁徙两层区间含 0，样本只有四五百种。
- 暴露轴在非雀形目与雀形目的留鸟中各自独立显著。
