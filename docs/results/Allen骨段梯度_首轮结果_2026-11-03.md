# Allen 骨段梯度首轮结果

Eliason 早成鸟的直接骨段比较支持温度响应由近端向远端增强；这一完整梯度不能直接推广到早成与半早成合并组、鸭科或全部鸟类的温度与觅食环境交互。

设计：[本轮方案](../design/Allen骨段梯度与口径修订_2026-11-03.md)。这是看过原有结果后的后续检验，不作为独立数据验证或未经探索的预注册。

运行目录：`outputs/allen_revision_v1_20261103_150249_076496/`。`SUCCESS.json` 确认骨段任务八棵树全部完成；它不代表公平 AIC 任务完成。完整表为 `gradient_results.csv`，个体模型设定在 `gradient_diagnostics.json`，样本名单在 `samples/`。实现通过 SciPy 矩阵正态似然核对、显式 Kronecker GLS 系数与协方差核对、行排列不变性、固定 lambda 下比例回归一致性，以及真实系统发育树上的两个种子合成梯度/零效应检查。这些是实现与恢复检查，不是对所有条件下错误率的全面校准。

## 早成鸟的直接比较

Eliason 非雀形目早成 P，259 种、31 科；不是 P+SP 的 317 种。主树 Hackett 21，控制体重、生活方式、栖境密度、迁徙等级和纬度跨度，三段联合拟合。同一模型的骨段差计入了骨段之间的相关性。

| 温度斜率之差 | 估计 | 未校正 95% 区间 | Holm 校正 p |
|---|---:|---|---:|
| 跗跖骨 − 胫跗骨 | +0.01481 | [+0.00958, +0.02003] | 0.000000381 |
| 胫跗骨 − 股骨 | +0.00821 | [+0.00223, +0.01420] | 0.02919 |
| 跗跖骨 − 股骨 | +0.02302 | [+0.01337, +0.03267] | 0.00002156 |

单位为每升温 10 °C 的 log10 长度变化之差。校正族包括本表三项及全部物种温度×X 交互的三项，共六项。估计 lambda 条件下的近似 t 区间，不含所有模型与系统发育不确定性。

八棵树上两个相邻差值均为正且通过各树预定校正。跗跖骨−胫跗骨的估计范围约 +0.01464 至 +0.01541，胫跗骨−股骨约 +0.00760 至 +0.00866。八棵树是敏感性检查，不是八份独立证据。

联合模型假设三段共享 lambda；另让三个 log 骨段比分别估计 lambda 时，两个相邻差值仍为正并通过校正：跗跖/胫跗 +0.01145 [+0.00669, +0.01621]，胫跗/股骨 +0.00606 [+0.00100, +0.01111]。不同模型的点估计不同，不可用新联合差值去拼接旧的逐骨段回归斜率。

可用正文表述：

> 在 Eliason 的早成鸟样本中，控制体重与生态协变量后，骨段间直接比较支持温度关联由股骨、胫跗骨至跗跖骨逐步增强；这一排序在所检验的八棵系统发育树上保持稳定。

这不是对每个骨段都随温度显著增长的断言，也不证明热调节是唯一成因。

## 不能一起扩大的结论

| 样本和问题 | 直接比较结果 | 可用表述 |
|---|---|---|
| Eliason 早成+半早成，317 种，温度斜率 | 跗跖强于胫跗及股骨；胫跗−股骨区间含零 | 支持远端响应较强，完整梯度证据不足 |
| Watanabe 鸭科，86 种，温度斜率 | 跗跖强于胫跗及股骨；胫跗−股骨区间含零 | 支持远端差异，不称完整梯度的独立复现 |
| Eliason 全部，1,035 种，温度×X 交互 | 点估计排序一致，但主树三个差值均未通过六项校正 | 尚不能确认暴露交互的骨段梯度 |
| Skelevision 纯雀形目，1,641 种，温度斜率 | 胫跗和跗跖均比股骨更负；胫跗与跗跖之差未检出 | 远端两段相对股骨的关联偏负，不是早成鸟正向梯度的简单延伸 |

全部物种交互的三个差值分别为 +0.00820、+0.00552、+0.01371，校正 p 分别约 0.0757、0.1320、0.0757。第一、三项未校正区间排除零，但仍按预定多重校正规则报告。比例回归独立估计 lambda 后也未确认该梯度；不从模型之间挑选显著结果。

## 馆藏号重叠

Eliason 和 Skelevision 有 49 个标准化馆藏号匹配，涉及 Eliason 的 41 个物种名。FMNH343713、FMNH343714 在两表中的名称不同，保留核查标志，不能直接宣称馆藏身份与分类已核实。见 `catalog_overlap_records.csv`。

把全部匹配行从 Eliason 原始表删除后，重新计算物种均值，全部物种两轴样本从 1,035 降到 1,008；交互梯度仍未确认。早成鸟主样本没有因这些匹配改变，因此其重算结果相同，不能把这当作增加了一次有信息量的独立验证。三来源数据不再统称完全独立。

## 运行与同步

本地 Windows 在 EvoWM 根目录提交本轮脚本、设计和结果文档后推送。服务器环境 evowm 和 tmux 内运行：

```bash
cd /mnt/zihanw/EvoWM
git pull --ff-only origin main
python scripts/allen/run_revision_v1.py --stage aic
```

该命令跑三组主树及其余七棵树的全部物种公平 AIC 比较。仅使用两个 CPU 数值库线程，不占 GPU。日志自动保存，不需要复制长脚本。末尾看到 SUCCESS 后下载它显示的整个目录 `outputs/allen_revision_v1_时间戳/`。如需在服务器复现本轮全部骨段与 AIC 分析，去掉 `--stage aic` 即可。
