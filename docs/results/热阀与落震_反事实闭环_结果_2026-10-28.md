# 热阀与落震：去散热腿的落震（结果，2026-10-28）

> 设计《热阀与落震_反事实闭环_设计_2026-10-28》，判据先定。一句话：**免费阀说成立。** 把 Allen 定律在露天鸟跗跖骨上造成的加长（20 °C 对应 7.2%）去掉，落震可行率一点没变（之差 +0.3 个百分点，区间 [−1.0, +1.6]），剂量到 40 °C 也不变；树栖雀形目反向操作同样不变。热阀的加长在落地上不付代价，这就是跗跖骨能被温度随意塑形的力学条件。世界模型（Q3）：预注册校准不通过（反事实连体重一起变，口径与 PGLS 不同），露天梯度通过；事后扣体重后方向全对、量偏弱，世界模型顺带把 Bergmann 定律学了出来。

## 符号与术语

- R：真实腿，类群中位数的三段骨长与体重。C：去散热腿，每段按它的温度斜率回推 $\Delta T$ 得到，体重不变。
- $p_F$ 可行率：256 组关节参数（所有腿共用，配对）× 6 个工况里，四道落震判据都满足的比例；方括号为按参数组自助重抽样 10,000 次的 95% 区间；有意义的差 = 5 个百分点。
- 次要读数：峰值合加速度（g）、腿行程（占腿长）、峰值地反力（倍体重）、缓冲效率 $\eta$，每组参数 6 个工况平均后与 R 的配对差中位数。

## 2　Q1　露天组：免费阀说成立

| 腿 | $p_F$ | 与 R 之差（百分点） |
|---|---|---|
| R 真实腿 | 31.8% | |
| C 10 °C | 31.7% | −0.1 [−0.8, +0.7] |
| **C 20 °C（主）** | 32.0% | **+0.3 [−1.0, +1.6]** |
| C 40 °C | 32.0% | +0.2 [−1.8, +2.2] |
| C 只回推跗跖骨 20 °C | 31.9% | +0.1 [−1.1, +1.4] |
| C 20 °C，速度按自身腿长缩放 | 32.6% | +0.8 [−0.5, +2.1] |

- 三个剂量下 $|\Delta p_F|$ 都 < 5 个百分点，判免费阀说。敏感性（行程上限 10%、20%，峰值上限 5 g）之差都在 ±2.1 个百分点内。
- 次要读数有方向：去散热（更短）的腿峰值加速度高 0.43 g（20 °C）、0.85 g（40 °C），腿行程少 1.2% 腿长，峰值地反力高 0.43 倍体重，$\eta$ 高 0.015。也就是 Allen 定律的加长让落地略软一点，但软的程度不改变可行与否。
- 失败率（求解、塌陷、深陷）1.2% 到 1.7%，各腿相近。

## 3　Q2　树栖雀形目：同样免费，方向相反但量极小

| 腿 | $p_F$ | 与 R 之差（百分点） |
|---|---|---|
| R 真实腿 | 29.7% | |
| C 10 °C | 29.3% | −0.4 [−0.8, 0.0] |
| **C 20 °C（主）** | 29.0% | **−0.7 [−1.3, −0.1]** |
| C 40 °C | 28.3% | −1.4 [−2.5, −0.5] |
| C 只回推跗跖骨 20 °C | 29.0% | −0.7 [−1.4, 0.0] |

- 去散热后雀形目的腿变长，可行率单调略降（$\rho$ = −1.0），但 40 °C 也只降 1.4 个百分点，同样落在免费阀说。次要读数：更长的腿峰值加速度低 0.14 g，行程多 0.5% 腿长。
- 两组方向相反（露天组缩短略不利，树栖组加长略不利），但两边都不到有意义的量。按设计第 5 节写明：落震对这个量级的长度变化不敏感，与类群无关。

## 4　解读

1. **热阀是免费的。** 温度在露天鸟跗跖骨上造成的全部变化范围（20 °C 对应 7.2%，40 °C 对应 14%）都在落震的不敏感区内。热与力学不冲突，所以跗跖骨可以被温度塑形而不付落地的代价。这是 Weeks 2025 翅骨故事（散热与敏捷性权衡）的反面：腿上没有权衡，有的是一段力学上自由的骨。
2. **为什么热阀落在跗跖骨而不是别处**，落震这一侧不给答案：被动落震对三段里哪一段缩短 7% 都不敏感（探索性的分段互换见第 5 节）。决定段的是热的一侧（只有跗跖骨裸露），力学只提供"允许"。
3. 论文写法：Allen 定律在鸟腿上找到的是"热收益最大、力学代价为零"的那一段。力学代价为零不是推论，是仿真结果。

## 5　探索：同样的缩短放在别的段（不进判据）

露天组真实腿 R 上，把 20 °C 的缩短量（−7.2%）分别只放在一段（`scripts/exploratory/drop_segment_swap_v0.py`，同一批参数与工况）：

| 腿 | 三段 mm | $p_F$ | 与 R 之差 |
|---|---|---|---|
| R | 50.1 / 80.9 / 50.6 | 31.8% | |
| 只缩跗跖骨 | 46.5 / 80.9 / 50.6 | 31.9% | +0.1 [−1.1, +1.4] |
| 只缩胫跗骨 | 50.1 / 75.2 / 50.6 | 31.7% | −0.1 [−0.7, +0.5] |
| 只缩股骨 | 50.1 / 80.9 / 47.0 | 31.8% | +0.1 [−0.1, +0.3] |

被动落震对三段里任何一段缩短 7% 都不敏感。所以"免费"不是跗跖骨独有的，力学这一侧不决定热阀落在哪一段；决定段的是热的一侧（只有跗跖骨裸露），力学提供的是"允许"。

## 6　Q3　世界模型：预注册的校准不通过，梯度通过

服务器 50 个模型（`outputs/thermal_v1/report.md`，71 万个留出科预测）：

- **校准（预注册口径）不通过**：外测跗跖的原始温度斜率，非雀形目暴露组 −0.0021 [−0.0052, +0.0020]（PGLS +0.0125），巢内组 −0.0076（PGLS +0.0034），雀形目 −0.0116（PGLS −0.0057）；鸭科跗跖骨 +0.0021 在区间内。4 项里 1 项在区间内，方向有错。按设计第 5 节，世界模型不作第二版反事实腿的引擎，只进附录。
- **原因看得清**：世界模型的反事实连体重一起变，每升高 10 °C 体重 −0.016 到 −0.022（log10，即小 4% 到 5%，Bergmann 定律的方向），跗跖按异速关系跟着变短；而 PGLS 的斜率是控制体重之后的。两者口径不同，是我写校准判据时的疏漏。事后修订 v1.1（`scripts/thermal/eval_thermal_v1_1.py`）用"该列斜率 − b × 体重斜率"与 PGLS 同口径再对一次，结果另记为事后，不改 v1 的判定。
- **梯度通过**：没有写交互项，模型推出的温度斜率仍随成鸟暴露 X 增加：非雀形目 X 每增加 1，斜率 +0.0078 [+0.0026, +0.0125]（3,231 种，96 科）；雀形目 +0.0023 [+0.0004, +0.0040]（4,889 种，97 科）。两组都为正。这是世界模型自己找到的露天梯度，但同样要在 v1.1 扣体重后复核。
- **线性**：三个 ΔT 的斜率接近，模型的温度响应是线性的。

**v1.1（事后修订，扣除体重后与 PGLS 同口径，`outputs/thermal_v1/report_v1_1.md`）：**

| 读数 | 世界模型（扣体重） | PGLS 参照 | 在区间内 |
|---|---|---|---|
| 非雀形目暴露组，外测跗跖 | +0.0029 [−0.0005, +0.0077] | +0.0125 [+0.0082, +0.0168] | 否（方向对，量只有四分之一） |
| 非雀形目巢内组，外测跗跖 | −0.0011 [−0.0073, +0.0044] | +0.0034 [−0.0003, +0.0071] | 否（两边都含 0） |
| 雀形目，外测跗跖 | −0.0072 [−0.0081, −0.0062] | −0.0057 [−0.0076, −0.0039] | 是 |
| 鸭科，跗跖骨 | +0.0023 | +0.0137 [+0.0010, +0.0265] | 是（偏弱） |
| 雀形目，跗跖骨 / 股骨 | +0.0008 / +0.0019 | −0.0008 / +0.0026 | 是 / 是 |

- 扣体重后 4 项里 2 项进区间，方向上露天组正、雀形目反向、鸭科跗跖骨正，都对；露天组的量被压到四分之一。按规则仍记"校准不通过"。
- 梯度扣体重后：雀形目仍为正 +0.0023 [+0.0006, +0.0037]；非雀形目 +0.0059 [−0.0015, +0.0138] 区间含 0。v1 里非雀形目的梯度有一部分来自体重响应随 X 变。
- **探索：世界模型的体重响应本身对不对。** 同样的 PGLS（协变量同主模型，不含体重）看体重对温度的斜率（Bergmann 定律）：非雀形目暴露组 −0.0284 [−0.0474, −0.0095]，巢内组 −0.0429 [−0.0556, −0.0302]，雀形目 −0.0150 [−0.0217, −0.0084]。世界模型给的 −0.0163、−0.0220、−0.0146：方向全对，暴露组与雀形目在区间内，巢内组略弱。世界模型没见过"Bergmann 定律"这个词，但把它学出来了，而且量级对。

闭环的判定（设计第 5 节"综合"）：Q1 有明确结论（免费阀），Q3 校准按预注册不通过，所以闭环靠 $E_{PGLS}$。世界模型进附录，能说的是：没有写任何定律，它自己推出了体重随温度变小（Bergmann，量级与 PGLS 一致）、露天鸟跗跖变长、树栖雀形目反向（方向与 PGLS 一致）、雀形目内的露天梯度；说不了的是效应量，露天组被压到 PGLS 的四分之一。
