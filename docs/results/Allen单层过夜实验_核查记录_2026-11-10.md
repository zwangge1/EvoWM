# Allen 单层过夜实验核查记录

记录日期：2026-11-10。运行发生于2026-11-04；本记录保存已经完成的单层模型结果，供后续两层实验和稿件引用。两层研究方向另见[讨论稿](../design/Allen两层解剖尺度预测_讨论稿_2026-11-10.md)。

## 核心结论

单层 EvoWM／JEPA 对外测跗跖、跗跖骨及跗跖／股骨比例的预测优于本次匹配输入的 Ridge 岭回归基线；股骨预测反而较差。早成鸟在三个温度共同推移时呈现远端较强的模型响应，但完整梯度依赖扰动口径，而且已知答案模拟中的骨段差异恢复未通过。

本次没有 OU 比较，不能写为“已经超过 OU”。四种方案都是单层 JEPA 的不同解剖输出组织，不能据此宣称 H-JEPA 的层级优势已经成立。

## 运行与评估口径

- 原始目录：[allen_overnight_v2_20261104_160812_916587](../../outputs/allen_overnight_v2_20261104_160812_916587/)。原始输出和检查点保留，不用新实验覆盖。
- 服务器代码提交：`2ef8e9af65d0949c56e2d8885c909671cfadc795`。该提交号须与运行目录内的源码快照、输入哈希和工作区状态共同使用。
- 280/280 任务完成，失败和待运行均为零；约耗时3小时8分钟。240个模拟任务各2000步，40个真实数据任务各4000步。
- 四种输出：flat、allocation、proximal、distal；两个种子13、14；按科五折0至4；主树Hackett 21。
- 服务器使用GPU 4、5、6、7，评估workers=32，loader workers=8，每训练任务计算线程4。
- 合并五折真实评估包含18,314个预测窗口、9,172个目标物种、194科。完整三骨预测包含1,096种、168科。重复窗口不是独立物种样本。
- 预测任务利用其他物种的已知形态与生态条件预测未参与训练的目标物种。验证上下文可以包含另外三个留出集物种的已知形态，故不等于“整科完全没有形态资料时从零预测”。目标物种的形态不进入其预测上下文。
- 先按窗口计算误差平方，在物种内平均，再在科内平均，最后各科等权；合并两个种子的误差平方后开方。不是直接平均各折RMSE。
- Ridge是匹配输入、固定alpha=1的线性基线；没有调优所有可能的线性或系统发育模型。模型预测使用训练中的读出，不在留出标签上重拟合读出。

## 真实数据预测表现

以flat为代表，RMSE单位为log10长度或log10比例；越小越好。改善比例为`(Ridge RMSE − JEPA RMSE) / Ridge RMSE`，不是解释方差比例或温度贡献比例。

| 目标 | 单层JEPA RMSE | Ridge RMSE | 相对结果 |
|---|---:|---:|---|
| 外测跗跖 | 0.09628 | 0.12188 | 误差降低约21.0% |
| 跗跖骨 | 0.10640 | 0.12633 | 降低约15.8% |
| 跗跖／股骨比例 | 0.09613 | 0.11609 | 降低约17.2% |
| 胫跗骨 | 0.07110 | 0.07575 | 小幅改善，配对区间含零 |
| 股骨 | 0.06219 | 0.05674 | 单层JEPA较差 |

前三项改善的按科配对bootstrap区间不含零；股骨的负向改善也不含零。股骨温度响应弱与股骨预测误差较大是不同结论，后者不能作为热暴露假说的支持。

四种输出组织相互比较未显示明确的实质优势。allocation相对flat的RMSE差分别为外测跗跖+0.000846、跗跖骨+0.000517、跗跖／股骨+0.000629，区间均含零。proximal与distal的主要预测结果也与flat非常接近。

来源：[预测配对比较](../../outputs/allen_overnight_v2_20261104_160812_916587/audit_real/prediction_paired_bootstrap.csv)、[架构配对比较](../../outputs/allen_overnight_v2_20261104_160812_916587/audit_real/architecture_paired_bootstrap.csv)、[各种子指标](../../outputs/allen_overnight_v2_20261104_160812_916587/audit_real/metrics_by_seed.csv)。

## 温度条件响应

非雀形目严格早成P、完整三骨且联合温度扰动在训练温度边际范围内：258种、31科、508窗口。不是P+SP，也不是此前生物学直接比较的259种完整集合。

将bio1、bio5、bio6共同推移，固定形态上下文、体重及其他条件，以±1°C中心差分换算每10°C的局部log10长度响应，flat结果如下。不是直接模拟完整10°C变化后的真实演化轨迹。

| 指标 | 模型响应 | 按科bootstrap 95%区间 |
|---|---:|---|
| 股骨 | −0.00266 | [−0.00609, +0.00084] |
| 胫跗骨 | +0.00862 | [+0.00673, +0.01053] |
| 跗跖骨 | +0.01883 | [+0.01580, +0.02199] |
| 跗跖骨−胫跗骨 | +0.01021 | [+0.00792, +0.01250] |
| 胫跗骨−股骨 | +0.01128 | [+0.00808, +0.01465] |

四种输出、两个种子在共同温度推移下的两个相邻差方向一致。只推移bio1、固定bio5和bio6时，股骨为+0.00759 [ +0.00485, +0.01025 ]，胫跗骨−股骨为+0.00162 [−0.00064, +0.00393]，完整三级阶梯不再明确。联合推移不能当作单一bio1的PGLS系数。

这些区间反映固定已训练模型下的科重抽样，不包括重新训练、换树或多重比较调整。温度支持检查只检查各维边际范围，不保证联合条件属于有充分观测支持的气候组合。

来源：[温度响应区间](../../outputs/allen_overnight_v2_20261104_160812_916587/audit_real/thermal_bootstrap.csv)、[各种子温度响应](../../outputs/allen_overnight_v2_20261104_160812_916587/audit_real/thermal_by_seed.csv)。

## 信息遮蔽

全样本flat跗跖骨预测中，遮蔽温度后RMSE增加0.00317 [0.00075, 0.00575]；遮蔽运动后增加0.00249 [−0.00378, 0.00869]。温度信息具有增量预测价值；运动信息贡献较不确定，不能据此证明运动无作用或温度主导演化。

股骨完整输入RMSE为0.062188，遮蔽温度后为0.062034，差异区间含零。不能把它相对Ridge的总体预测劣势归因于加入温度。

各骨段是否因温度信息获得不同幅度的改善，需要直接比较改善量，不能仅凭一项区间排除零、另一项包含零来证明两项不同。

## 已知答案模拟

全部240个模拟任务的原始窗口重算后，48份“架构×场景×种子”报告与原`calibration.json`完全一致，最大数值差为零。四架构的通过模式相同：

| 场景 | 每架构通过种子数 |
|---|---:|
| null，无温度效应 | 2/2 |
| motion，仅运动效应 | 2/2 |
| equal，三个骨段温度效应相同 | 2/2 |
| temperature，正向骨段梯度 | 0/2 |
| joint，温度受暴露调节并有运动效应 | 0/2 |
| reverse，反向骨段梯度 | 0/2 |

判据是三骨斜率及两个相邻差的绝对恢复误差不超过`max(0.003, 0.5 × |真值|)`，使用同一支持样本及相同科权重。这是开发容差，不是正式假阳性率或功效校准。

纯温度场景的股／胫跗／跗跖真值为0／0.006／0.015；flat种子13约为0.00602／0.00736／0.00912，种子14约为0.00330／0.00730／0.00627。跗跖−股骨差只恢复约20%，说明差异明显被压缩。

模拟只由bio1产生温度效应，但模型在单独bio5、bio6扰动时也有响应。联合推移后仍未恢复骨段差，故不能仅以温度口径不同解释失败。null联合平均读数通过，也不表示全部单温度读数均没有假效应。

## 训练与跨环境复现

所有模型都是`num_levels=1`，评估为单步预测；allocation是单层表示上的总长与分配读出，不是两层JEPA。所有任务完成规定步数，读出参与训练。训练末段损失趋平且最终学习率为零，不能简单把模拟失败归结为任务中断，也不能直接恢复原终点调度来延长训练。

本地与服务器的冻结折有1258行不同，其余非模拟协变量一致，真实标签也在float32误差内一致。已定位到pandas不同版本对同样大小科的排序差异；改变并列排序可完整重建服务器194科映射。本次内部跨架构与种子的划分一致，不能因该差异否定内部比较。后续复评须沿用保存的冻结映射并校验，不能静默重新分折。

## 稿件可用表述

> 在按科留出的开发性评估中，单层EvoWM相对匹配输入的岭回归降低了外测跗跖、跗跖骨和跗跖／股骨比例的预测误差。早成鸟在共同温度推移下呈现远端较强的模型响应，但该排序对温度扰动方式敏感，且已知答案模拟的骨段差异恢复未通过，因此目前将其作为预测与方法开发结果。

OU比较、两层架构增益、跨领域泛化及演化机制识别，分别属于后续待验证的问题。
