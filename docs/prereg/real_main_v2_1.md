# 预注册修订 v2.1：真实数据主分析 v2 的进入条件与 H2 的地位（2026-10-15）

修订 `docs/prereg/real_main_v2.md`（提交 402f345）。本修订在第 0 阶段 v2 的结果出来之后、任何真实数据模型训练之前写定；除下文第 2 节的两点外，v2 的全部内容不变（数据、模型与动作、训练、树与种子、读数、基线、探索性分析、局限）。

## 1. 起因

v2 规定第 0 阶段 G1 到 G3 全部满足才进入真实数据。第 0 阶段 v2（`docs/results/real_main_v2_stage0.md`）：

- G1、G2 在新种子 11、12 上都通过：运动方式变化对上的相对跗跖 E1，效应 +0.0019 [+0.0009, +0.0030]、+0.0027 [+0.0016, +0.0040]，零模型 −0.0006、−0.0005。这两条是 H1 读数自己的校准。
- G3 只在种子 11 上未通过：E2 的 ρ 为 0.961、0.968，达标；零模型 m_tarsus 对比平均绝对值占效应的比例为 27%（界限 25%），种子 12 为 2%。种子 11 的零模型里所有类别相对栖树都偏 +0.002 到 +0.007，是模型从这次背景实现里学到的假效应。效应情景两个种子的涉水、空中检查都通过，E2 的判定方式为零模型阈值（0.0062）。

按 v2，真实数据没有训练。

## 2. 修订内容

1. **进入条件**：第 0 阶段 G1、G2 都通过，即训练并评估真实数据。
2. **G3 只决定 H2 的地位**：G3 通过时，H2a 到 H2c 与 v2 完全相同；G3 未通过时（本次即如此），H2a 到 H2c 只作描述：报告合并对比、95% 区间、各运行方向一致比例、是否超过零模型阈值，不写"支持"或"相反"，也不作为论文的确认性结论。H1 单独检验，α = 0.025 单侧。v2 中 E2 为零模型阈值模式时 H2 本来就不进 Holm，所以 H1 的检验方法与 v2 完全相同。

## 3. 理由

- G3 检查的是 E2 读数是否干净，它的失败不涉及 E1 的校准；按 v2 的写法，H1 会因为与 H1 无关的原因被挡住。
- 把 H2 降为描述，是对 G3 失败的保守处理。本修订没有放宽 H1 的任何判据，也没有提升任何读数的地位。
- 不采用的做法：不换新种子原样重跑第 0 阶段（一道门槛未通过就换种子重试，直到通过为止，这道门槛就失去了意义）；不在此时改 E2 的算法（例如相对所有类别的平均来比，可以消除种子 11 那种整体偏移），留作后续研究，另写预注册。
