# 预注册：真实数据主分析 v1（第一层，2026-10-14）

接续模拟恢复检验 v4（通过，`docs/results/sim_recovery_v4.md`）。本文件写定真实数据上要回答的问题、读数、判定规则与先行校准。
任何真实数据模型的训练与评估，都在本文件提交、且第 0 阶段校准通过之后才开始。允许零结果，结果如实报告。
本研究只用 H-JEPA 的第一层；第二、三层是后续研究，另写预注册。

## 1. 要回答的问题

1. **E1 习性的可迁移预测价值**：在没见过的科上，知道一个物种的生态习性，能否让模型更准地预测它的相对腿长（跗跖扣除体型）？这是本文的主要新结论。
2. **E2 运动方式的反事实对比**：把物种的生态描述换成某种运动方式的典型描述，预测的相对腿长往哪个方向变。只解释方向和排序（模拟中数值约为真实偏移的三分之一）。其中三条是已知规律，作为真实数据上的正对照。
3. **E3 近亲信息的衰减（描述）**：模型对近亲腿长的依赖随进化距离衰减的快慢。真实数据的相对跗跖接近布朗运动（第 10 节），这个读数不能解释为"腿长适应习性的半衰期"，只与第 0 阶段模拟和 OU 基线并列描述。
4. **世界模型相对线性模型多了什么**：同一批窗口上，用系统发育线性模型（方案二的线性极限）做 E1，与世界模型比较。

## 2. 数据

- 物种主表 `data/processed/species_traits.csv`（9,993 种，md5 872bcc14eecae132a83d5f3dec5ea299）。AVONET 推断值已置缺。
- 纳入：跗跖与体重都有实测的物种，9,583 种，194 个科、40 个目。全部纳入，不剔除不飞鸟。
- 运动方式（`src/evowm/sim/regimes.py` 的 `regime_locomotor`，与模拟相同）：栖树 5,582，地栖 1,924，泛化 854，空中 771，涉水 190，潜水 154，水面 108。用于定义"习性变化的物种对"和 E2 的类别。
- 相对跗跖 = log10 跗跖 − b × log10 体重，b 为每折训练物种上的 OLS 斜率（与 v4 相同）。
- 系统发育树：Hackett 100 棵后验树（`data/raw/birdtree/hackett_100.nwk`，sha256 见 `data/MANIFEST.md`）。用到的单棵树由 `scripts/extract_trees.py` 取出到 `data/processed/trees/`，md5 写在同目录的 `MANIFEST.txt`。

## 3. 模型与训练

- 与 v4 完全相同：单层，4,000 步，批量 128，50% 样带置零习性，单卡 fp32，配置 `configs/hjepa/recovery_v3_l1.yaml`；按科 5 折交叉验证（`family_folds`，seed 0）。真实数据没有另设测试集：每个读数都在训练时没见过的科上计算，不在真实数据上调任何参数。
- **用单棵后验树训练，树当作重复**：取后验树第 21、41、61、81、100 棵（固定），每棵树、每个训练种子（1、2）各训练 5 折，共 5 × 2 × 5 = 50 个模型。理由：v4 验证的是"单棵树"配置；把 100 棵树混在一起训练会让半衰期偏长（v2 约 1.7 倍），而单棵树的偏差可以在第 0 阶段量出来。
- 稳健性（不判定）：Ericson 后验树第 21、41、61 棵，训练种子 1，各 5 折，共 15 个模型（服务器上没有 Ericson 树文件时跳过）。

## 4. 第 0 阶段：树不对、背景接近真实时的模拟校准（门槛，真实数据之前完成）

真实数据只能在"可能不对的树"上训练；v4 用的是生成数据的那棵真树，而且 v4 的模拟几乎没有深层系统发育结构。第 0 阶段在这两点上都向真实数据靠拢，再检查读数是否还成立。

- **模拟**（`scripts/sim_recovery_tables.py --version v5 --seeds 9 10 --bg-rate 7.8e-4 --bg-eb -0.025`）：
  - 习性部分与 v4 相同：运动方式体制下的 OU（t½ 12 Myr，平稳 SD 0.06），效应情景的腿长偏移同 v4，零模型无偏移；数据在 Hackett 第 1 棵树上生成，新种子 9、10。
  - 新增：每个潜变量加一个独立的"早期爆发"布朗背景，根处速率 7.8 × 10⁻⁴（log10² / Myr），速率随距根时间 t 按 e^(−0.025 t) 递减。两个参数按真实数据相对跗跖残差（OLS：log 跗跖 ~ log 体重 + 运动方式）的总方差（SD 0.123）与科内方差（SD 0.067）设定，用 20 次背景实现的平均值求出，校准时只用种子 1234（背景）与 99（检查），不用种子 9、10。检查（种子 99，零模型）：残差 SD 0.101，科内 SD 0.067，目内 SD 0.084（真实 0.086），平稳 OU 拟合的 t½ 远大于树深（真实数据同样如此）。
  - 生成的表（服务器上用同一命令重新生成，应得到相同文件）md5：effect_s9 65a0fd14c96e9176261ae9f36ed21166，effect_s10 8e7447393f5a069ef4ccd0a4b18e6144，null_s9 ba87c9668e2d61bdcc58970199cf060c，null_s10 782cf98ba51bc634bd45b292f2ccce81。
- **训练**：用第 21、41、61、81、100 棵树（都不是生成数据的树），每个情景、种子、树各 5 折，训练种子等于数据种子，共 2 × 2 × 5 × 5 = 100 个模型。
- **判据**（全部满足才进入真实数据）：
  - **G1**：效应情景，两个种子各自的相对跗跖 E1（5 棵树、5 折合并，按科自助重抽样 10,000 次）95% 区间下限大于 0。
  - **G2**：零模型，两个种子各自的相对跗跖 E1，区间含 0，或小于效应同种子的 10%。
  - **G3**：效应情景两个种子，E2 对比（树与折平均）在可识别组合上与真值偏移的 Spearman ρ 都 ≥ 0.7；零模型 m_tarsus 相对对比平均绝对值都小于效应的 25%。
- **同时按固定规则确定 E2 的判定方式**（不看真实数据）：
  - 零模型两个种子共 12 个对比（6 类 × 2），逐窗口相对对比按科自助重抽样，95% 区间不含 0 的个数不超过 10%（即至多 1 个），就用"按科重抽样"；否则看按目重抽样，同样至多 1 个，就用"按目重抽样"。
  - 两级都超过，改用**零模型阈值**：零模型每次运行（2 个种子 × 5 棵树）各运动方式的对比（5 折窗口合并后的均值）取绝对值，共 60 个，其 95% 分位数记为 T。真实数据中对比超过 T 才算显著。
  - 检查（不阻止进入真实数据）：效应情景两个种子的涉水 > 0、空中 < 0 应按所选方式判为显著。检查不通过时，真实数据 H2 的"不确定"注明"模拟中这个检验功效不足"。
- **E3 参照**：效应与零模型各自全部运行的 t½（每棵树合并 5 折拟合，带振幅）中位数，只作真实数据 E3 的参照；有布朗背景时 E3 没有单一真值，不再做校准。
- 第 0 阶段不通过：不跑真实数据，先报告原因。

## 5. 判定用读数与假设（真实数据，50 个模型）

所有读数都在观测空间（log10）计算；10 次运行（5 棵树 × 2 个种子）的预测合并后，以"科"为单位自助重抽样 10,000 次（E2 按第 0 阶段确定的方式）。同时报告每次运行的结果。

- **H1（主要）**：相对跗跖 E1 增益（全部相邻对）大于 0。单侧自助 p 值 = 重抽样增益 ≤ 0 的比例。
- **H2 正对照（E2，相对跗跖，各类相对栖树）**：H2a 涉水 > 0；H2b 地栖 > 0；H2c 空中 < 0（"飞得越好腿越短"在运动方式层面的表现）。
- **多重检验**：
  - 第 0 阶段定为按科或按目重抽样时：H1 与 H2a 到 H2c 共 4 个检验，用预期方向的单侧 p 值做 Holm 校正，总体 α = 0.025（单侧，等价于双侧 0.05）。被拒绝的零假设判为"支持"；H2 未被拒绝、但 95% 区间在相反方向上不含 0 的判为"相反"；其余为"不确定"（H1 为"未检出"）。
  - 第 0 阶段定为零模型阈值时：H1 单独检验，α = 0.025 单侧。H2 不进 Holm：合并对比在预期方向上超过 T 判为"支持"，在相反方向上超过 T 判为"相反"，其余为"不确定"。
- **结论用语**：H1 支持时写"习性对相对腿长有可迁移的预测价值"；未检出时写"未检出"，并注明第 0 阶段零模型下这个读数的表现，不能当作"没有作用"的证据。
- **稳健性要求**：H2 每次运行的点估计方向一致的比例不低于 80%，否则在结论中注明"随树或种子不稳定"。
- **E3（描述，不设假设）**：报告 10 次运行各自合并拟合的 t½ 的中位数与范围，与第 0 阶段参照、OU 基线并列。
- **世界模型对线性模型（描述，不设假设）**：线性基线在同一批窗口上预测相对跗跖：有习性时 r̂_B = μ_c(B) + exp(−αd)(r_A − μ_c(A))，无习性时把 μ_c 换成训练物种的总体均值；μ_c 为训练物种各运动方式的平均相对跗跖，两个版本的 α 各自在训练科的窗口上用最小二乘拟合。报告线性 E1、世界模型 E1，以及两者之差的自助区间。

## 6. 基线（描述）

- PGLS：log 跗跖 ~ log 体重 + 运动方式（栖树为基准），Pagel λ 用最大似然估计，全部 9,583 种，在第 21、41、61、81、100 棵树上各拟合一次；系数方向与 E2 并列。
- 平稳 OU 回归：同一模型，误差为平稳 OU 加测量误差，每棵树随机取 2,000 种（固定种子 0），最大似然估计 t½；与 E3 并列。
- 旧 PIC 结果：HWI 与相对腿长约 56% 的分支上方向相反（`data/prior_results/S3_pic_signtest.csv`），作为 H2c 的背景。
- 旧 OU 半衰期：u 约 12.3 Myr，HWI 约 14.6 Myr（`data/prior_results/S2_lability.csv`）。

## 8. 已知局限（写进论文）

- E2 的数值约为真实偏移的三分之一，只解释方向与排序，不当作效应大小。
- 模型由生态信息猜体重的过拟合没有修，所有判定读数都扣除了体型；绝对腿长与体重的读数只作诊断。
- 模拟只验证了"习性改变腿长截距"这一种作用方式；真实数据里习性若改变异速斜率，模型可能捕捉到，但读数没有专门检验。
- 运动方式由 AVONET 生活方式与 EltonTraits 觅食层导出，类别较粗；E2 的"典型描述"是该类物种生态变量的平均，包含食性、栖息地等，不只是运动方式本身。
- 第 0 阶段的背景只按相对跗跖残差的两个方差分量对齐真实数据（一棵树、OLS 残差），各潜变量相互独立，体重与其他性状的结构没有对齐；它是"足够像"的检查，不是拟合出来的演化模型。
- 零模型阈值（若用到）只来自 2 个零模型实现，是粗略的参照，不是有严格错误率的检验。
- E3 在有布朗背景的数据上没有单一真值，只作描述。
