# 预注册：按习性尺度分层的主分析 v1（第二、三层，2026-10-15）

接续第一层的真实数据主分析 v2.1（`docs/prereg/real_main_v2_1.md`，结果 `docs/results/real_main_v2_1.md`：H1 支持）。分层设计见 `docs/design/第二层设计草案_2026-10-15.md`，开发检查见 `docs/results/dev_units_v1.md`（代码提交 74d15a7）。本文件在开发检查之后、第 0 阶段与任何第二、三层真实数据模型训练之前写定。任何真实数据模型的训练与评估，都在本文件提交、且第 0 阶段通过之后才开始。允许零结果，结果如实报告。

## 1. 要回答的问题

1. **H3 运动方式转变在类群一级的可迁移预测价值（主要）**：在没见过的科上，一群近亲（叶序上连续、运动方式相同的物种）从一种明确的运动方式换成另一种明确的运动方式时，知道这一习性变化，能否让第二层更准地预测新一群的典型相对腿长（成员的平均相对跗跖）？
2. **H4 第二层的反事实方向**：把一群鸟的平均习性换成"某种运动方式的典型描述"，预测的典型相对腿长往哪个方向变。三条已知规律作为正对照。
3. **第三层（描述）**：在陆、水、空之间转变时，腿与体型的变化。
4. **次要与描述**（S1 到 S5）：联合训练对第一层的影响；运动方式相同的近亲之间细习性的作用；线性基线；子集；第二层对第一层。

## 2. 数据

- 物种主表 `data/processed/species_traits.csv`（9,993 种，md5 872bcc14eecae132a83d5f3dec5ea299）；纳入跗跖与体重都有实测的 9,583 种，与 v2 相同。
- 运动方式（`src/evowm/sim/regimes.py` 的 `regime_locomotor`，与 v2 相同的 7 类）：栖树、地栖、泛化、空中、涉水、潜水、水面。栖境：陆 = 栖树、地栖、泛化；水 = 涉水、潜水、水面；空 = 空中。都只由习性列导出。
- **单位**（`src/evowm/data/units.py`）：每条随机旋转的深度优先叶序上，连续的、运动方式相同的物种为一个第二层单位；连续的、栖境相同的物种为一个第三层单位（由完整的第二层单位组成）。叶序上缺失类别的物种沿用前一种的类别（纳入的物种都有类别）。
- 相对跗跖 = log10 跗跖 − b × log10 体重，b 为每折训练物种上的 OLS 斜率；单位的目标值为成员的平均。
- **不涉及泛化的转变**：前一个单位与目标单位的运动方式都不是"泛化"的第二层步。
- 系统发育树：与 v2 相同（Hackett 100 棵后验树；Ericson 树作稳健性），单棵树由 `scripts/extract_trees.py` 取出。

## 3. 模型与训练

- 配置 `configs/hjepa/recovery_v5_hab3.yaml`（三层，开发检查按设计草案第 6 节的规则保留第三层）。第一层与 v2 的 `recovery_v5_l1` 完全相同（第一层损失与上游逐位相同）。
- **第二层**：状态为单位内各物种第一层嵌入的掩码平均（训练时每个单位至多随机抽 16 种，评估用全部成员）再经第二层编码器；动作为两单位平均习性之差（只在两边都有数据的列上）、各习性组"两边都有数据"的标记、两单位成员之间的平均进化距离（对数与线性），52 维，与第一层同构；历史 3、预测 1；损失为表示空间的教师强制一步预测 MSE 加 SIGReg。
- **第三层**：状态为所含第二层单位表示的掩码平均（训练时至多抽 8 个，每个至多 16 种）再经第三层编码器；动作同第二层，在栖境单位一级计算。
- 三层联合训练，总损失为各层之和，上层梯度回传到下层（H-JEPA 原样）；4,000 步，批量 128，学习率各层 3e-4，50% 的样本把所有层动作的习性部分置零（只留距离），单卡 fp32，按科 5 折交叉验证（`family_folds`，seed 0）。
- 真实数据：Hackett 后验树第 21、41、61、81、100 棵 × 训练种子 1、2 × 5 折 = 50 个模型；稳健性（不判定）：Ericson 后验树第 21、41、61 棵 × 种子 1 × 5 折 = 15 个模型（服务器上没有 Ericson 树文件时跳过）。
- 评估脚本检查每个检查点的动作方式为 change、上层单位为运动方式与栖境两层，不符合就停止。不在真实数据上调任何参数。

## 4. 第 0 阶段：树不对、背景接近真实时的模拟校准（门槛）

- **模拟**（`scripts/sim_recovery_tables.py --version v5 --seeds 13 14 --bg-rate 7.8e-4 --bg-eb -0.025`）：与 v2 第 0 阶段的设定相同（运动方式体制下的 OU，t½ 12 Myr，平稳 SD 0.06，效应情景的腿长偏移同 v4；另加早期爆发布朗背景；数据在 Hackett 第 1 棵树上生成）。新种子 13、14，md5：effect_s13 c03d34812c279fc7e815730dcaec32ec，null_s13 fa8c609ed17ebb17be853cd7a73973ad，effect_s14 0423f490c2213e0744ec2830895defdf，null_s14 cb3c6b33419ffb604deca8cb9edb45d0（服务器上用同一命令重新生成，应得到相同文件）。
- **训练**：第 21、41、61、81、100 棵树，每个情景、种子、树各 5 折，训练种子等于数据种子，共 100 个三层模型。
- **判据**（全部满足才进入真实数据）：
  - **G1-L2**：效应情景，两个种子各自的 H3 读数（不涉及泛化的第二层步上的相对跗跖增益；5 棵树、5 折合并，按科自助重抽样 10,000 次）95% 区间下限大于 0。
  - **G2-L2**：零模型，两个种子各自的同一读数，区间含 0，或小于效应同种子的 10%。
  - **G-L1**：联合训练后的第一层仍满足 v2 的 G1、G2（运动方式变化对上的相对跗跖增益）。
- **G3-L2**（只决定 H4 的地位，不阻止进入真实数据）：效应情景两个种子，第二层反事实对比（6 类相对栖树，相对跗跖，树与折合并）与真值腿长偏移（跗跖骨潜变量）的 Spearman ρ 都 ≥ 0.7；零模型对比平均绝对值都小于效应的 25%。
- **E2 的判定方式**（固定规则，同 v2）：零模型两个种子共 12 个对比，按科自助重抽样的 95% 区间不含 0 的至多 1 个，就用"按科重抽样"；否则看按目重抽样，同样至多 1 个，就用"按目重抽样"；两级都超过，改用零模型阈值 T：零模型每次运行（2 个种子 × 5 棵树）各类对比（5 折合并后的均值）取绝对值，共 60 个，其 95% 分位数。检查（不阻止进入真实数据）：效应情景两个种子的涉水 > 0、空中 < 0 应按所选方式判为显著；不通过时，真实数据 H4 的"不确定"注明"模拟中这个检验功效不足"。
- 第三层与其余读数照常报告，不作判据。第 0 阶段不通过：不跑真实数据，先报告原因。

## 5. 判定用读数与假设（真实数据，50 个模型）

所有读数在观测空间（log10）计算；10 次运行（5 棵树 × 2 个种子）的预测合并后，以"科"为单位自助重抽样 10,000 次（单位归属其成员里最多的科；E2 按第 0 阶段确定的方式）。同时报告每次运行的结果。

- **H3（主要）**：不涉及泛化的第二层步上，相对跗跖的习性增益大于 0。增益 = 无习性 RMSE − 有习性 RMSE，"无习性"即把第二层动作的习性部分置零、保留距离；预测取留出科叶序上全部连续 4 个单位的窗口（历史 1 到 3，与第一层 E1 的取法相同），每个折 8 条叶序。单侧自助 p 值 = 重抽样增益 ≤ 0 的比例。
- **H4（第二层反事实，相对跗跖，各类相对栖树）**：H4a 涉水 > 0；H4b 地栖 > 0；H4c 空中 < 0。每个窗口的第 1 个单位作上下文，下一个单位的平均习性换成该类的典型值（训练单位的类别平均，只用各习性组都有数据的单位），距离用真实值。
- **多重检验与地位**：
  - G3-L2 通过、E2 定为按科或按目重抽样：H3 与 H4a 到 H4c 共 4 个检验，用预期方向的单侧 p 值做 Holm 校正，总体 α = 0.025。被拒绝的零假设判为"支持"；H4 未被拒绝、但 95% 区间在相反方向上不含 0 的判为"相反"；其余为"不确定"（H3 为"未检出"）。
  - G3-L2 通过、E2 定为零模型阈值：H3 单独检验，α = 0.025 单侧。H4 不进 Holm：合并对比在预期方向上超过 T 判为"支持"，在相反方向上超过 T 判为"相反"，其余为"不确定"。
  - G3-L2 未通过：H3 单独检验，α = 0.025 单侧；H4 只作描述（对比、区间、各运行方向一致的比例、是否超过零模型阈值），不写"支持"或"相反"（同 v2.1）。
- **结论用语**：H3 支持时写"在两种明确的运动方式之间转变时，习性变化对新类群的典型相对腿长有可迁移的预测价值"；未检出时写"未检出"，并注明第 0 阶段零模型下这个读数的表现，不能当作"没有作用"的证据。
- **稳健性要求**：H4 每次运行的点估计方向一致的比例不低于 80%，否则在结论中注明"随树或种子不稳定"。

## 6. 次要读数与描述（不设假设）

- **全部第二层步**（含涉及泛化的转变）上的相对跗跖增益。
- **第三层**：栖境转变的相对跗跖、体重、HWI 增益；反事实（水、空相对陆地）的相对跗跖、体重、HWI 对比。模拟里没有设定栖境对体型的效应，这些读数没有校准，只作描述。
- **S1 联合训练对第一层的影响**：三层模型的第一层与 v2.1 只训第一层的模型（同树、同种子、同折，同一套窗口）在运动方式变化对上的相对跗跖增益，及其配对差的自助区间。
- **S2 运动方式相同的近亲**：第一层在运动方式相同的相邻对上的相对跗跖增益（v2.1 的模型与三层模型）。
- **S3 线性基线**：单位一级，无习性 r̂_B = μ + exp(−αd)(r_A − μ)，只用变化时再加 κ(μ_c(B) − μ_c(A))（μ、μ_c 为训练单位的总体与各运动方式均值，α、κ 在训练科叶序的相邻单位上最小二乘拟合，κ 限制在 [0, 1]）；报告线性增益与世界模型减线性的区间（全部与不涉及泛化）。
- **S4 子集**：目标段只有 1 种与多于 1 种；目标段长度 2 到 4、5 到 16、超过 16 种。
- **S5 第二层对第一层**：预测留出单位的平均相对跗跖，第二层一步预测，对比第一层从目标单位前面紧邻的 3 种出发的一步直跳与逐种连推；报告 RMSE 与差的区间。
- **Ericson 树**：H3 读数与 H4 对比（15 个模型）。

## 8. 已知局限（写进论文）

- 分层在本研究中的作用是让"运动方式转变决定腿的方向"能在类群一级检验，不是提高预测精度：开发检查中第二层预测单位平均腿长的误差大于第一层（S5）。
- 单位按 AVONET 与 EltonTraits 的类别切分，类别在叶端会来回变；一半的第二层单位只有 1 种。H3 只覆盖两种明确运动方式之间的转变，不涉及"泛化"。
- 单位的目标值是成员平均，长单位的平均跨越较远的亲缘。
- 按习性事件分块是对 H-JEPA 的扩展（上游为固定步长），登记在 `hjepa/UPSTREAM.md`。
- 模拟只验证了"习性改变腿长截距"这一种作用方式；第三层的体型读数在模拟里没有校准。
- 零模型阈值（若用到）只来自 2 个零模型实现，是粗略的参照。
- 开发检查中零模型的第二层反事实有少量假效应（为效应的 13% 到 18%）。
- 第一层的局限同 v2 第 8 节。
