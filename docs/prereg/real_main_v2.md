# 预注册：真实数据主分析 v2（第一层，动作只含习性变化，2026-10-15）

接续 v1（`docs/prereg/real_main_v1.md`，提交 1129e5d）。v1 的第 0 阶段未通过 G1，真实数据模型没有训练（`docs/results/real_main_v1_stage0.md`）。事后诊断与开发检查都在模拟上进行（第 10 节），结果表明：v1 的动作里含目标种习性的绝对值，模型因此把习性当作"水平"用；在祖传结构强的数据上，这种用法不能跨科迁移。v2 只改这一点：动作只含近亲之间的习性变化。第 0 阶段换新种子重新校准。任何真实数据模型的训练与评估，都在本文件提交、且第 0 阶段通过之后才开始。允许零结果，结果如实报告。本研究只用 H-JEPA 的第一层；第二、三层是后续研究，另写预注册。

## 1. 要回答的问题

1. **E1 习性变化的可迁移预测价值（主要）**：在没见过的科上，一个物种相对于最近的亲戚改变了运动方式，知道这一变化能否让模型更准地预测它的相对腿长（跗跖扣除体型）？主读数只在运动方式发生变化的相邻物种对上计算；全部相邻对上的 E1 作为次要读数，它也包含食性、栖息地等其他习性变量的变化。
2. **E2 运动方式的反事实对比**：把物种相对近亲的习性变化换成"变成某种运动方式的典型描述"，预测的相对腿长往哪个方向变。只解释方向和排序。其中三条是已知规律，作为真实数据上的正对照。
3. **E3 近亲信息的衰减（描述）**：模型对近亲腿长的依赖随进化距离衰减的快慢。真实数据的相对跗跖接近布朗运动（第 10 节），这个读数不能解释为"腿长适应习性的半衰期"，只与第 0 阶段模拟和 OU 基线并列描述。
4. **世界模型相对线性模型多了什么**：同一批窗口上，用只含习性变化的系统发育线性模型做 E1，与世界模型比较。

与 v1 的第 0 阶段相同（模拟设定、训练树、判定方式的规则），只改三处：动作只含习性变化；新种子 11、12；G1、G2 改用运动方式变化对上的 E1。

- **模拟**（`scripts/sim_recovery_tables.py --version v5 --seeds 11 12 --bg-rate 7.8e-4 --bg-eb -0.025`）：习性部分同 v4（运动方式体制下的 OU，t½ 12 Myr，平稳 SD 0.06；效应情景的腿长偏移同 v4，零模型无偏移），另加每个潜变量独立的"早期爆发"布朗背景（参数的来历见 v1 第 4 节）；数据在 Hackett 第 1 棵树上生成。生成的表（服务器上用同一命令重新生成，应得到相同文件）md5：effect_s11 b17f2f94da12bc2b3761488fa095d377，null_s11 080cd3fc9fb5e7037a0a97685659d00d，effect_s12 05ccac9813f4058e96c2145f5e065334，null_s12 cf8a8ef9188db1f484b23f8a286cb086。
- **训练**：第 21、41、61、81、100 棵树（都不是生成数据的树），每个情景、种子、树各 5 折，训练种子等于数据种子，共 100 个模型。
- **判据**（全部满足才进入真实数据）：
  - **G1**：效应情景，两个种子各自在运动方式变化对上的相对跗跖 E1（5 棵树、5 折合并，按科自助重抽样 10,000 次）95% 区间下限大于 0。
  - **G2**：零模型，两个种子各自的同一读数，区间含 0，或小于效应同种子的 10%。
  - **G3**：效应情景两个种子，E2 对比（树与折平均）在可识别组合上与真值偏移的 Spearman ρ 都 ≥ 0.7；零模型 m_tarsus 相对对比平均绝对值都小于效应的 25%。
  - 全部相邻对上的 E1 照常报告，不作判据。
- **E2 的判定方式**（按固定规则，不看真实数据，同 v1）：零模型两个种子共 12 个对比，逐窗口相对对比按科自助重抽样，95% 区间不含 0 的至多 1 个，就用"按科重抽样"；否则看按目重抽样，同样至多 1 个，就用"按目重抽样"；两级都超过，改用零模型阈值 T：零模型每次运行（2 个种子 × 5 棵树）各运动方式的对比（5 折窗口合并后的均值）取绝对值，共 60 个，其 95% 分位数。检查（不阻止进入真实数据）：效应情景两个种子的涉水 > 0、空中 < 0 应按所选方式判为显著；检查不通过时，真实数据 H2 的"不确定"注明"模拟中这个检验功效不足"。
- **E3 参照**：效应与零模型各自全部运行的 t½（每棵树合并 5 折拟合，带振幅）中位数，只作真实数据 E3 的参照。

## 5. 判定用读数与假设（真实数据，50 个模型）

所有读数都在观测空间（log10）计算；10 次运行（5 棵树 × 2 个种子）的预测合并后，以"科"为单位自助重抽样 10,000 次（E2 按第 0 阶段确定的方式）。同时报告每次运行的结果。

- **H1（主要）**：运动方式变化对上的相对跗跖 E1 增益大于 0。单侧自助 p 值 = 重抽样增益 ≤ 0 的比例。
- **H2 正对照（E2，相对跗跖，各类相对栖树）**：H2a 涉水 > 0；H2b 地栖 > 0；H2c 空中 < 0（"飞得越好腿越短"在运动方式层面的表现）。
- **多重检验**（同 v1）：
  - 第 0 阶段定为按科或按目重抽样时：H1 与 H2a 到 H2c 共 4 个检验，用预期方向的单侧 p 值做 Holm 校正，总体 α = 0.025（单侧，等价于双侧 0.05）。被拒绝的零假设判为"支持"；H2 未被拒绝、但 95% 区间在相反方向上不含 0 的判为"相反"；其余为"不确定"（H1 为"未检出"）。
  - 第 0 阶段定为零模型阈值时：H1 单独检验，α = 0.025 单侧。H2 不进 Holm：合并对比在预期方向上超过 T 判为"支持"，在相反方向上超过 T 判为"相反"，其余为"不确定"。
- **结论用语**：H1 支持时写"运动方式的转变对相对腿长的变化有可迁移的预测价值"；未检出时写"未检出"，并注明第 0 阶段零模型下这个读数的表现，不能当作"没有作用"的证据。
- **次要读数（描述）**：全部相邻对上的相对跗跖 E1 及其区间。
- **稳健性要求**：H2 每次运行的点估计方向一致的比例不低于 80%，否则在结论中注明"随树或种子不稳定"。
- **E3（描述，不设假设）**：报告 10 次运行各自合并拟合的 t½ 的中位数与范围，与第 0 阶段参照、OU 基线并列。
- **世界模型对线性模型（描述，不设假设）**：线性基线在同一批窗口上预测相对跗跖：无习性时 r̂_B = μ + exp(−αd)(r_A − μ)；习性只当变化用时再加 κ(μ_c(B) − μ_c(A))，只在近亲之间运动方式不同时起作用。μ、μ_c 为训练物种的总体均值与各运动方式的均值，α 与 κ 在训练科的窗口上用最小二乘拟合（κ 限制在 [0, 1]）。报告线性 E1（变化对与全部相邻对）、世界模型减线性基线的自助区间；v1 的"习性当水平用"版本作为参照一并报告。

## 6. 基线（描述）

- PGLS：log 跗跖 ~ log 体重 + 运动方式（栖树为基准），Pagel λ 用最大似然估计，全部 9,583 种，在第 21、41、61、81、100 棵树上各拟合一次；系数方向与 E2 并列。
- 平稳 OU 回归：同一模型，误差为平稳 OU 加测量误差，每棵树随机取 2,000 种（固定种子 0），最大似然估计 t½；与 E3 并列。
- 旧 PIC 结果：HWI 与相对腿长约 56% 的分支上方向相反（`data/prior_results/S3_pic_signtest.csv`），作为 H2c 的背景。
- 旧 OU 半衰期：u 约 12.3 Myr，HWI 约 14.6 Myr（`data/prior_results/S2_lability.csv`）。

## 8. 已知局限（写进论文）

- E2 的数值小于真实偏移，只解释方向与排序，不当作效应大小。
- 模型由生态信息猜体重的过拟合在 v2 下明显减小但仍在（开发检查中体重 E1 为 −0.0008 到 −0.0012），所有判定读数都扣除了体型；绝对腿长与体重的读数只作诊断。
- 主读数只用运动方式发生变化的物种对，类别较粗；其他习性变量的作用只进入次要读数。运动方式由 AVONET 生活方式与 EltonTraits 觅食层导出，E2 的"典型描述"是该类物种生态变量的平均，不只是运动方式本身。
- 模型只看到近亲之间的习性变化，结论是"变化预测变化"，不涉及静态的习性与形态关联。
- 开发检查中，零模型在变化对上的 E1 略为负（模型学到少量假的变化效应），使 H1 偏保守。
- 模拟只验证了"习性改变腿长截距"这一种作用方式；第 0 阶段的背景只按相对跗跖残差的两个方差分量对齐真实数据（一棵树、OLS 残差），各潜变量相互独立；它是"足够像"的检查，不是拟合出来的演化模型。
- 零模型阈值（若用到）只来自 2 个零模型实现，是粗略的参照，不是有严格错误率的检验。
- E3 在有布朗背景的数据上没有单一真值，只作描述。
