# 发育方式与腿的 Allen 定律 v2：巢型、骨长复现、分段（设计与判据，2026-10-27）

> 接《发育方式与腿的Allen定律_结果_2026-10-26》：主判据过了，但分不开发育方式与生活方式，翅长也分成同样两组。本文用两份新数据再设三个检验，专门为"腿在生长期暴露于环境温度"这个机制找能证伪它的地方。判据在跑之前定下。

## 符号与术语

- **巢内组 / 暴露组**：同 v1。巢内组 = 半晚成 + 晚成；暴露组 = 早成 + 半早成。
- **巢型**（Cooney 等 2020，Nat Commun，3,096 种）：open 开放巢、mixed 混合、closed 封闭巢（有顶）、cavity 洞巢。封闭巢与洞巢的热缓冲比开放巢强，雏鸟经历的温度波动更小。
- **留巢期**：Cooney 的 fledging period（$\log_{10}$ 天）。对巢内组是雏鸟在巢里长的天数；对早成鸟是到首飞的天数，不是在巢天数。
- **骨长**（Eliason、Proffitt 与 Clarke 2023，Evolution，Dryad CC0）：股骨、胫跗骨、跗跖骨、肱骨、桡尺骨、腕掌骨，1,246 种，物种均值由标本平均；对上 BirdTree 约 1,125 种（非雀形目约 777）。
- 温度系数：温度每升高 10 °C，$\log_{10}$ 长度的变化；0.0043 对应 1%。协变量同 v1。

## 1. 三个检验

### T1 巢的热缓冲（机制的直接预测）

若机制是"生长期暴露于环境温度"，那么在巢内组里，开放巢的雏鸟比洞巢、封闭巢的雏鸟更暴露，开放巢物种的跗跖温度斜率应更接近 Allen（更正），洞巢与封闭巢应更接近 0 或更负。替代解释（支系各有策略）不预测巢型有差别。

模型（PGLS）：巢内组物种（含雀形目），$\log_{10}$ 跗跖 ~ $M$ + $T$ + $T \times$ 开放巢 + 开放巢 + 协变量。开放巢 = open；对照 = cavity + closed；mixed 不用。分别在雀形目内、非雀形目巢内组内、合并三套跑。

判据：T1 支持机制，若合并样本里 $T \times$ 开放巢的系数为正、95% 区间不含 0、点估计 ≥ 0.0043，且雀形目内同号。T1 反对机制，若合并样本区间含 0 或为负。

### T2 用骨长复现发育方式的两组

v1 用的是 AVONET 外测跗跖。用 Eliason 的跗跖骨长在非雀形目上重做 v1 主模型（暴露组对巢内组）。

判据：T2 复现，若暴露组斜率 > 0、区间不含 0，且之差区间不含 0。否则记"骨长上未复现"。

### T3 分段：Allen 定律在暴露组里是否只落在跗跖骨

这是 10-21 那条分段假说的正确战场：雀形目全是巢内组、没有 Allen 定律，所以当时两层都为零。暴露组有 Allen 定律，分段预测才有意义。

模型：暴露组物种（Eliason，非雀形目），三段各做一次 $\log_{10}$ 骨长 ~ $M$ + $T$ + 协变量，再做 $r = \log_{10}(\text{跗跖骨}/\text{股骨})$。

判据：T3 支持分段，若暴露组里跗跖骨温度系数 > 0 且区间不含 0，股骨区间含 0 或点估计 < 跗跖骨的一半，$r$ 系数 > 0 且区间不含 0。三段都正且 $r$ 区间含 0 为"整腿 Allen"。巢内组同样跑一遍作对照（预期三段都接近 0）。

### 探索（不判定）

- 留巢期作连续变量：巢内组里 $T \times \log$ 留巢期；暴露组里 $T \times \log$ 到首飞天数。
- 半早成单独一组的斜率（鸥、燕鸥、夜鹰、鸊鷉、潜鸟、火烈鸟）。
- 翅骨（肱骨）在两组的温度斜率，看翅骨是否像翅羽那样也分两组。

## 2. 综合判定（运行前定）

- **机制得到支持**：T1 支持且 T2 复现。T3 另算，支持则故事完整。
- **机制被证伪**：T1 反对（开放巢与洞巢无差别或反向）且 T2 复现：两组现象是真的，但不是生长期暴露造成的，论文主张改为"支系分化"。
- **数据不足**：T2 未复现：骨长与外测跗跖不一致，先查匹配与测量，不下结论。
