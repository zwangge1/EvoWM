# Allen 不对称观测实验 v1

2026-11-12。任务是检验模型在骨骼测量稀少、分类群覆盖不均及参考资料不完整时的信息利用效率。沿用既有模型；不改变输出坐标、损失权重或骨段响应方向。实验设计在新实验结果产生前固定，但原外层物种已经参与此前方法开发，因此本轮属于开发性评估，不称独立确认或公开预注册。

## 科学问题与判读

1. 完整三骨测量减少时，保留全部可用外测跗跖、生态信息能否帮助预测骨长和骨段比例？
2. 相同测量数量集中于少数科时，模型能否推广到资料不足的类群？
3. 对固定已训练模型，参考鸟三骨资料减少或缺一骨段时，误差增加多少？

比较完整两层 JEPA、单层 JEPA、纯监督两层、BM、OU。后两者是现有四性状联合系统发育条件模型，含生态主效应与预先定义交互、性状协方差和观测噪声。它们也使用全部可用外测资料，不能仅在完整三骨记录上拟合。OU 使用现有共享 alpha、固定根参数化，不代表所有可能的 OU 扩展。

关注绝对误差与相对完整记录的误差增加。增长较小但起点较差，不自动等于更好的预测；两项同时展示。所有结果保留，不根据有利程度删条件或切换主指标。差异不显著不能推出等效或不劣。本轮不预设可接受误差界值，不作不劣宣称。

## 训练资料条件

采用完成并核查的原始 v3 真实数据、五个冻结的整科外折和原始验证窗口。不可按当前 pandas 版本重新生成折。

| 条件 | 保留原训练完整三骨数 | 选择方式 |
|---|---:|---|
| complete100 | 100% | 原始全部可用资料 |
| uniform50 | 50% | 按物种稳定随机排序保留 |
| uniform25 | 25% | 同一排序，嵌套于 50% |
| family50 | 50% | 先随机排序科，再按科集中保留 |
| family25 | 25% | 同一排序，嵌套于 50% |

保留数为 floor(N × 比例)。同折、同重复下两种缺失机制的完整三骨数完全相同。按科集中保留时优先整科保留，仅边界科按稳定物种排序取足数量，因此不能称完全按科缺失；记录边界科与各科覆盖数量。随机机制模拟测量机会分散，按科机制模拟分类研究偏倚，均不代表全部真实缺失机制。

有两个配对重复：(mask_seed=101, training_seed=13)、(mask_seed=202, training_seed=14)。掩码与训练种子配对，不能分别估计二者方差。所有架构使用相同删失表、参考窗口和可见信息。BM/OU 在每个表重新拟合。

只移除原有的三骨测量，不制造新标签，不以外测跗跖代替三骨真值。三骨成组移除，使现有经典模型的精确嵌套缺失似然仍适用。训练表中相关旧骨字段、样本数与骨数据来源也一并清除；按实际字段记录。其他模型输入保持不变。

删失通过独立物理 CSV 实现，发生在构造数据集之前。隐藏值不得出现在参考 pixels、JEPA 目标编码、监督损失、读出归一化或任何派生总长/比例中。保留所有物种行、树节点和外测记录，不能因骨值缺失删掉物种。测试目标真值仅用于最终评分；其所在外折仍不进入训练。

## 预测时参考资料条件

每个模型在相同三个参考鸟、相同目标与窗口上评估以下四项。三个参考属于外折可见参考资料，此任务是有参考的系统发育条件预测，不是完全无外折形态信息的零样本预测。

| reference_case | 处理 |
|---|---|
| observed | 保留参考资料的原有缺失状况 |
| hide_half_bones | 用稳定物种哈希遮蔽约一半参考物种的三骨记录 |
| hide_all_bones | 遮蔽全部参考三骨，保留外测跗跖 |
| hide_distal | 遮蔽参考跗跖骨，保留原本可见的其他性状 |

同一个物种在同条件的不同窗口中具有相同可见状态，不能以窗口为单位重新抽缺失。新增遮蔽只移除原本可见信息，不恢复自然缺失。神经模型同时清零对应标准化值与观测掩码；BM/OU 仅条件化相同的可见坐标。目标骨真值完全不进入预测。

has_reference_bones 固定指原始参考窗口中至少存在一个骨观测，各条件不变；另记录遮蔽后的观测数。除全体目标外，报告这一固定子集，避免大量原本已无参考骨骼的窗口稀释压力测试。它是基于参考输入的条件子集，不是根据模型表现挑选。

这是冻结模型的压力测试，没有额外训练参考删失增强。hide_distal 等模式可能超出原训练缺失模式，解释时注明。生态条件本轮保持原状；生态缺失及公平的联合插补比较留待后续，不能将本轮称为所有不完整数据场景的验证。

## 模型与资源

全程沿用 allen_v3_full / single / supervised 的原始配置：4000 步、batch 128、相同掩码概率和损失权重，无调参选择；loader workers 固定 4，禁用训练前 sanity validation 与训练期 validation。读出统计仅用各自删失后的训练表。

完整矩阵：5 折 × 2 重复 × 5 条件 × 3 神经架构 = 150 次训练；5 × 2 × 5 = 50 个经典拟合任务，每个包括 BM 和 OU；共 200 个作业。每个结果评估 4 种参考条件。

smoke：第 0 折、第 0 重复，complete100/uniform25/family25 三条件、三架构，共 9 个 64 步训练与 3 个经典任务。经典任务仍使用该折完整训练物种，保证检查真实输入接口。smoke 仅作通路验证，不作科学结果。

最多 4 张用户选定的 GPU；每卡同时训练一个作业。CPU 默认 32 个神经评估 worker、4 个经典 worker（各 2 线程），每个神经评估 1 个数值线程。支持 WORKERS=64 或 EVAL_WORKERS=64；不将每个任务再设为 64 个 BLAS 线程。

## 评分、配对与输出

主要指标 allocation_logratio_joint：log10(股骨/跗跖骨)、log10(胫跗骨/跗跖骨) 两个坐标的均方误差等权。次级指标为四个长度、三骨总长及两个骨比，保持旧实验口径。骨相关指标仅在同一完整三骨真值支持上比较；外测跗跖使用全部可评分观测。

先在目标物种内平均窗口平方误差，再在科内平均物种，随后平均两个配对重复的科误差，最后科等权平均并开平方。不能把重复窗口当作独立物种，不能把重复训练当作独立科。报告科配对 bootstrap 的描述性 95% 区间，区间不包含完整重新训练、重新选择配置和换树不确定性。

预定主要读取 uniform25 / family25 的 observed 条件下，full 对 OU、single、supervised 的绝对 RMSE 差；并计算相对于 complete100 的误差增量差。所有 50% 条件、BM 对照与参考压力条件同时保存。正的 competitor−full 差表示 full 误差较低；正的增量差表示 full 恶化较小。需结合绝对误差读取。

每个作业保存原始逐窗口预测、可见参考状态摘要、训练保留数、条件设计、拟合诊断和完成状态。汇总保存 summary.csv、comparisons.csv、per_family_errors.csv、summary.json。归档输入掩码、代码、git 版本、运行环境及 SHA256；review 包排除权重，不删除服务器原始训练文件。

## 服务器命令

从 EvoWM 仓库根目录执行。先按 nvidia-smi 选择当前可用的 1—4 张卡，下例卡号仅作示例。

```bash
SOURCE_RUN=outputs/allen_overnight_v3_20261110_150810_454903
GPUS="0 1 2 3" WORKERS=32 HOURS=2 bash scripts/allen_world/run_asymmetry_v1.sh --source-run "$SOURCE_RUN" --smoke
```

smoke 成功后执行完整矩阵：

```bash
GPUS="0 1 2 3" WORKERS=32 HOURS=12 bash scripts/allen_world/run_asymmetry_v1.sh --source-run "$SOURCE_RUN" --full
```

HOURS 是停止派发新任务的时间预算，不是每个模型训练时长；已经启动的任务及其评分会完成。退出码 0=完成、1=失败、2=时间预算耗尽。最后打印 DOWNLOAD=..._review.tar.gz。续跑保留已完成作业及训练权重：

```bash
GPUS="0 1 2 3" WORKERS=32 HOURS=12 bash scripts/allen_world/run_asymmetry_v1.sh --resume outputs/allen_asymmetry_v1_具体时间
```

失败任务在检查日志后可用 --retry-failed 重试。中断产物保留到 attempts；不得并发续跑同一目录。续跑验证代码和输入哈希，代码改变时开启新实验。
