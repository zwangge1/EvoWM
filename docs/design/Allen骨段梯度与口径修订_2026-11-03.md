# Allen 骨段梯度与口径修订

本轮先修正样本来源和模型比较口径，再直接检验骨段间的响应差。生物学比较是主线，演化模型用于推演生态转变对应的形态方向，力学只做辅助验证。热收益推演暂不作为本轮任务。

这是看过既有结果后的后续分析方案，不能称为未接触数据的预注册。以下判据在本轮新检验运行前固定，所有方向、零结果和敏感性结果一并输出。

## 科学问题与样本

三段顺序为股骨 fem、胫跗骨 tbt、跗跖骨 tmt。跗跖读 fū zhí。胫跗骨覆盖情况随物种变化，不能把整段胫跗骨都定义为裸露骨段；觅食环境指标 X 也不是实测裸露面积或裸露时间。

主检验 A：Eliason 非雀形目早成 P 物种，三段骨长对年均温的关联是否从近端向远端增强。使用 P 是为了衔接旧图 2 的早成鸟样本；P+SP 暴露组另作次级分析，不互换名称。

主检验 B：Eliason 全部物种，在体型与觅食环境同放的模型中，温度 × X 的关联是否从近端向远端增强。X 为地面、水面附近、水下觅食比例之和；体型为 log10 体重。这里的交互差不是主检验 A 的温度斜率差。

每一检验只用三段齐全、该模型协变量齐全的同一批物种，保存名单。A 不因缺少 X 删种；B 需要 X。Eliason 保留原处理口径，先对原始毫米数取物种均值再取 log10；已有 Skelevision/Watanabe 物种表保留其原口径。三段齐全指物种级，不保证每根骨来自同一件标本。

次级结果：Eliason P+SP、巢内非雀形目、雀形目；Skelevision 纯雀形目与 Watanabe 鸭科分别检验温度斜率。来源以 src_skeleton 核验，绝不把混合骨骼样本标为纯雀形目。Eliason 非雀形目的两轴模型另作次级结果。

## 联合模型和直接差值

响应为三列 log10 骨长，Y = XB + E。误差采用矩阵正态分布，物种间协方差为 V(lambda)，三骨段间允许完整的 3 × 3 协方差 Sigma。V(lambda) 为 Pagel lambda 缩放的系统发育协方差；lambda 用联合最大似然估计，检查 0、1 两端。此模型假设三骨段共享同一 lambda，必须以独立拟合的 log 骨段比例检查这一假设对结论的影响。

矩阵正态形式参考 [SciPy matrix_normal 文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.matrix_normal.html)。实现以其 logpdf 验证联合似然，并与显式 Kronecker 协方差 GLS 核对系数和协方差。每个骨段有自己的完整回归系数。

A 模型：截距、log10 体重、年均温/10、栖境密度、迁徙等级、纬度跨度/10、生活方式哑变量。B 模型额外含 X、T×M、T×X；M 和 X 按当前样本中心化。只移除常数或线性冗余的协变量；若目标主效应或交互不可估，记录失败，不静默删去。温度斜率单位为每 10 °C 的 log10 变化；T×X 为 X 增加 1 时这一斜率的变化。

从同一联合模型直接计算：

- 跗跖骨 − 胫跗骨：远端是否强于中段。
- 胫跗骨 − 股骨：中段是否强于近端。
- 跗跖骨 − 股骨：远近端总体差异。

差值标准误使用完整骨段间协方差，不能把两个独立标准误直接平方相加。另拟合三个 log10 长度比，各自估 lambda，作为协方差设定的敏感性结果，不取代联合主模型，不在两者中择优。

区间为估计 lambda 条件下、使用 n-p 残差自由度的近似 t 区间，不称为科自助重抽样区间，也不包含全部 lambda 和模型选择不确定性。主树原始样本的 A、B 共六个双侧差值检验构成一个 Holm 校正族；次级样本和每套敏感性各自按三个差值校正，仅作一致性检查。区间为未校正 95% 区间，判定用校正后 p < 0.05。

## 结论判据

两个相邻差值均为正且通过校正，才写“温度响应（或温度×X 交互）由近端向远端增强”。仅远近端差异成立，写“跗跖骨响应强于股骨”，不称完整梯度。中段和远端均强于近端而两者之差未检出，则只写这两个比较。只有点估计排序则写“呈排序趋势，骨段间差异证据不足”。负方向同样完整报告。股骨未显著不是股骨为零或等效性证明。

主树 Hackett 21；稳定性使用 Hackett 41、61、81、100 和 Ericson 21、41、61。比较同一共同物种集，输出全部八棵的主检验，不对树数再当作八次独立复制。主树跑全套次级与去重敏感性，其余树跑原样本 A、B。八棵只是抽样树的敏感性范围，不代表积分掉全部系统发育不确定性。

1. 旧图 2 的 Skelevision 1,641 种标签混用了 1,727 种混合样本系数。重新拟合纯雀形目四项（包括原输出缺少的胫跗骨），与其余三个图组一起输出统一 fig2_source.csv 和新版图。图 2 为旧式逐响应 PGLS 描述图，直接差值结论来自联合模型，不能从该图显著性排序。
2. 两轴比较的新 M0–M3 全部包含 T、M、X 及相同协变量；仅 T×M、T×X 是否加入不同。同一温度、同一物种、同一树比较 AIC。旧 M1 缺 X 主效应，旧 AIC 差不能解释为两种交互本身的优势。保留旧脚本和输出，新结果写独立目录。主树三组（全部、非雀形目、雀形目），其余七树只跑全部物种，校正八树 AIC 的旧说法。
3. Eliason 与 Skelevision 对标准化馆藏号做精确匹配，输出原名和骨长字段供检查。不据此断言所有匹配已获馆藏确证；名称冲突也保留。敏感性从 Eliason 原始行去除全部匹配馆藏号后重新算物种均值，再重跑 A、B。没有匹配到不等于完全独立；不再统称三份完全独立数据。

## 执行与交付

入口 scripts/allen/run_revision_v1.py。先运行合成数据与数值校验，再允许拟合真实数据。默认全部任务八棵树；--stage gradient 只跑骨段；--stage aic 只跑公平比较；--trees primary 只跑 Hackett 21；--check-only 仅检查输入、样本与实现，不拟合真实数据。

每次创建 outputs/allen_revision_v1_时间戳，保存源码和输入 SHA256、Git 提交和改动状态、依赖版本、样本名单、排除名单、结果 CSV、中文报告、图 2 PNG/PDF 及 console.log。完成才写 SUCCESS.json；失败保留日志并返回非零。计算仅用 CPU，默认两个数值库线程，不用 A100 显卡。代码在本地提交推送，服务器 git pull 后直接运行；回传整个输出目录。

本轮输出用于修订正文及图注。冷热分工、早晚成假说比较、演化模型与力学叙事在骨段结果回传后统一调整；不提前写成梯度成立。
