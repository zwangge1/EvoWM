# 探索：全身形态在哪一层随习性变（设计，2026-10-18）

> 起因：主分析的生物学结论可靠，但"习性变化预测腿长方向"比较方法早已知道，世界模型也没比线性模型好。这里找只有分层框架能给出的结果，检验一个猜想：不同身体部位在不同的习性尺度上随习性变化。探索性分析，不作判定；有信号再按惯例写预注册做确认。

## 符号与术语

- **第一层**：物种一级。**第二层**：运动方式单位（叶序上连续、运动方式相同的一段物种）。**第三层**：栖境单位（陆、水、空；涉水算水）。
- **栖境内改变**：前后两步的运动方式不同、栖境相同（如栖树到地栖）。**跨栖境改变**：栖境也不同（如陆到空、陆到水）。第三层的步都是跨栖境。
- **相对习性增益**：$1 - \mathrm{RMSE}(\hat y^{+}) / \mathrm{RMSE}(\hat y^{0})$，即告诉模型习性变化后误差减少的比例（$\hat y^{+}$、$\hat y^{0}$ 为带与不带习性变化的预测）。长度类形态先扣除体重通路（值 $- b \times$ 体重，$b$ 为该折训练物种上的斜率），体重与 HWI 不扣。
- **组**：后肢（跗跖、股骨、胫跗骨、跗跖骨）；飞行（翅长、Kipp 距离、HWI、肱骨、尺骨、桡骨、腕掌骨、龙骨）；喙（4 项）；其他（尾、次级飞羽、第二指、叉骨、头骨、巩膜环）；体重。
- **反事实对比**：把下一步的习性换成某一类的典型值，读出与基准类（栖树；栖境为陆地）的差，以训练物种（单位）的标准差为单位。
- **线性基线**：每项形态各自的"只用变化"线性基线（主分析 S3 的做法推广到 23 项），与世界模型用同一批预测比较。
- **模型集**：real_hab3（主分析 50 个三层模型）、real_hab3_ericson（15 个）、real_l1（v2.1 只训第一层的 50 个，"不分层"对照）、sim_v5_effect 与 sim_v5_null（主分析第 0 阶段的模拟与模型）、sim_v6_hab3 与 sim_v6_l1（新的全身模块模拟上新训练的模型）。
- **v6 模拟**：在 v5 上加一条：飞行器官的最优值只随栖境变（空中更长更尖、龙骨更大，水中略小），喙与其他形态不随习性变；腿与 v5 相同，随运动方式变。种子 15、16，脚本 `scripts/sim_modular_tables.py`。这些偏移是模拟的真值设定，不是对真实鸟类的断言。

## 1. 猜想

1. 后肢的比例随运动方式调整：栖境内的改变（栖树到地栖）就有习性增益，第二层最清楚。
2. 飞行器官随栖境调整：增益集中在跨栖境的改变上，第三层最清楚。
3. 喙与其他形态不随运动方式和栖境变（阴性对照）。
4. 分层的优势：同一信号在高层单位上（成员平均去掉了物种噪声）比在物种层、比不分层的模型更清楚。

## 2. 做法

- 主分析的模型不重训：23 项形态本来就在模型输入里，评估时每项拟合一个探针读回。
- 逐层、逐类型（不变、栖境内、跨栖境）、逐形态计算：相对习性增益、反事实对比、线性基线、世界模型对线性；按科自助重抽样（2,000 次）。
- 校准：v5 效应（只有腿随运动方式变）与 v5 零模型（已有 100 个模型）；v6 全身模块（新训练 50 个三层与 50 个只训第一层的模型）。

## 3. 怎么看结果

1. 先看模拟。v6 的三层模型要能恢复模块：后肢在栖境内有增益；飞行器官只在跨栖境与第三层有增益；喙与其他接近 0；反事实与真值同号。v5 零模型应全部接近 0。模拟里恢复不了的读数，真实数据上不解读。
2. 再看分层对不分层：v6 三层模型的第二、三层是否比只训第一层的模型信噪比更高。
3. 最后看真实数据：各组在各层、各类型上的增益与反事实方向，以及与线性基线的差。

## 4. 局限

- 骨骼形态（龙骨、肱骨等）基本只有雀形目测过，水鸟几乎没有，跨栖境的骨骼读数样本少；AVONET 的翅长、Kipp 距离、HWI 覆盖全部物种。
- 探索性：同一批真实数据上看很多读数，有信号也要再做确认（新的预注册、外部数据如 Wright 2016 的龙骨与飞行肌）。
- 真实数据只用主分析的留出类群，不碰岛屿对，岛屿检验 I2 仍是干净的外部检验。

## 5. 运行

`GPUS="0 1 2 3" bash scripts/run_explore_modules_v1.sh`：先评估现有模型并写中间报告（只用 CPU），再生成 v6 模拟表、训练 100 个模型（GPU 约 3 小时）、评估并写最终报告。结果在 `outputs/explore_modules_v1/report.md`，另有 `traits_gain.csv`、`contrasts.csv`。
