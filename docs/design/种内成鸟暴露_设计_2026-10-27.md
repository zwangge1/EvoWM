# 种内层面：成鸟暴露是否预测跗跖骨对温度的种内响应（设计与判据，2026-10-27）

> 证据链的第三层。跨物种（外测与骨长）已显示：腿的 Allen 定律只落在跗跖骨，强度随成年后腿的露天程度变，树栖雀形目反向。本检验问同一件事在种内是否成立：同一物种的不同标本来自不同温度的采集点，地面活动多的物种，其跗跖骨的种内温度斜率应比树栖物种更正。判据在跑之前定下。

## 符号与术语

- 数据：UMMZ 标本级主表（`data/processed/specimens.csv`），清洗与样本同 M2（《标本级变异_分段Allen定律_设计》第 3.3 节）：成体、雌雄已知、有采集点温度、不在分布范围外、无圈养字样；主样本 = 留鸟全年 + 迁徙种繁殖季，每种 ≥ 5 件且纬度跨度 ≥ 10°（85 种，约 1,058 件）。
- $X_j$：物种 $j$ 的成鸟暴露，EltonTraits 地面 + 水面附近 + 水下觅食比例之和（雀形目里基本就是地面觅食比例）。
- $\tilde T_{ij}$：标本采集点年均温，种内中心化，单位 10 °C。
- 响应：$\log_{10}$ 跗跖骨（主）、股骨、$r$ = 跗跖骨 − 股骨。

## 模型（混合模型，REML）

$$y_{ij} = \alpha_j + \beta_j \tilde T_{ij} + \gamma\,(\tilde T_{ij} X_j) + \delta\,\mathrm{sex}_{ij} + \theta\,\mathrm{year}_{ij} + e_{ij}, \qquad \alpha_j \sim N(\alpha, \sigma_\alpha^2),\ \beta_j \sim N(\beta, \sigma_\beta^2)$$

$\gamma$ 是核心量：成鸟暴露每增加 1（从纯树栖到纯地面），种内温度斜率增加多少。$\beta$ 是 $X = 0$（纯树栖）物种的种内斜率；$\beta + \gamma$ 是 $X = 1$ 物种的。随机斜率不收敛时退回随机截距并注明。

## 判据（运行前定下）

- **最小关心效应**：$\gamma \ge 0.0043$（露天程度从 0 到 1，斜率增加每 10 °C 1%）。
- **通过**：跗跖骨的 $\gamma > 0$、95% 区间不含 0、点估计 ≥ 0.0043；且股骨的 $\gamma$ 区间含 0 或点估计 < 跗跖骨的一半（分段）。$r$ 的 $\gamma$ 同号作辅助。
- **不通过**：跗跖骨 $\gamma$ 区间含 0 或为负。
- **整腿版**：跗跖骨与股骨的 $\gamma$ 都为正且区间不含 0：种内有露天效应但不分段，按实记。

## 稳健性（都跑，不进判据）

全部标本不限月份（121 种）；每种 ≥ 10 件；含个体体重版；最热月与最冷月温度；$X$ 换成只用地面觅食比例。
