# Allen BM OU 预测基线设计与运行

2026-11-11。为已完成的两层EvoWM v3增加经典系统发育条件预测基线。比较问题是：在相同生态条件、参考物种形态及留出科任务下，BM和OU能否预测目标鸟的外测跗跖、三骨长度、总长和比例。方案在查看本轮BM/OU真实预测误差前固定；不改写已有EvoWM训练与预测。

## 文献与模型定位

[Gardner等2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12229690/)区分仅使用回归系数的预测方程与利用目标亲缘位置、已知近亲残差的系统发育条件预测。本轮采用后者。[phylolm官方文档](https://search.r-project.org/CRAN/refmans/phylolm/html/phylolm.html)提供BM和固定根/随机根OU残差模型；[Rphylopars文档](https://cran.r-project.org/web/packages/Rphylopars/refman/Rphylopars.html)提供多性状与缺失观测的经典比较框架。本轮为这些高斯系统发育模型的Python实现及任务适配，不以简单距离衰减叠加Ridge代替OU。

主模型为共同树协方差的四性状高斯回归，Y=XB+U，cov(U)=K⊗Σ。B为生态条件的回归系数，Σ为四性状残差协方差。BM采用根至共同祖先的共享枝长核；OU采用固定根残差为零的OU核，参数alpha对四性状共同，alpha=0严格还原BM。这是可分离的多性状OU特例，不声称拟合了一般相互作用漂移矩阵，也不是重建祖先生态历史或最优值沿分支改变的机制模型。

树枝长统一除以完整源树高度，记录尺度与alpha原单位；不按训练子树重新缩放。允许估计共同的tip误差比例eta，使K=K_process+eta I；四性状tip误差协方差为etaΣ。这是比例误差约束，不是逐性状独立测量误差估计。模型名称及输出明确记录该项，eta=0边界纳入优化。

训练数据具有嵌套缺失模式：三骨同时观测，其物种均有外测跗跖。利用此结构，完整联合似然精确分解成外测跗跖的边缘似然与三骨给定同种外测跗跖的条件似然；后者为矩阵正态GLS。参数用完整训练观测的精确ML估计，不先填补骨长、不将重复窗口作为独立物种，不用复合似然代替联合似然。若缺失模式不满足条件，明确失败，不静默删观测适配。

## 同任务与可见信息

来源固定为`outputs/allen_overnight_v3_20261110_150810_454903`的observed表、唯一一棵冻结树、五个科分折及50份真实模型评估。使用保存的`context_0_tip`至`context_2_tip`恢复参考窗口，逐个核对目标、参考顺序、观测值和科归属。训练种子13/14对应神经网络训练，保存的评估采样种子实际为0；BM/OU没有两个随机训练种子，不伪造十次独立拟合。每个fold每种经典模型只训练一次，再与两训练种子的神经网络结果配对。

这是“参数训练未使用留出科、预测时给定该科参考性状”的条件预测任务。测试窗口允许三个参考鸟的已观测四性状，不允许目标鸟的任何骨长、外测长度或其总长/比例进入预测。参考可能来自留出科，故不称为完全没有该科性状支持的零样本任务。BM/OU参数只从训练科估计；测试参考只用于冻结参数的高斯条件更新。

主预测条件于同一个窗口三个参考的可见性状；不额外把其他测试物种真值放进参考池。所有训练数据已经用于全局参数估计，但本轮不额外对全体训练残差作GP条件更新，确保条件预测的参考集合与现有任务对应。均值预测和近亲修正分别保存，供核查实际使用的条件信息。

## 均值设计

读取源metadata的22项生态条件：三个温度、七项觅食层位、五项生活方式、四项发育方式、体重/栖境密度/迁徙等级。使用训练均值与标准差归一化，缺失填训练均值并提供缺失标记。所有合法条件同时输入，不要求OU先选唯一演化驱动。

默认包含全部条件主效应，以及三个温度分别与体重、觅食各分量、发育类别和生活方式类别的交互，使传统基线有机会表达待检验的调节关系。候选列按固定顺序，只依据训练预测变量及三骨观测支持的秩删去不可识别列；不根据系数、p值或测试误差筛列。保存列名、缩放、删除原因和实际支持。比例保持源表取值，不修改原EvoWM数据。X不新增为重复输入。

四性状共享此可识别设计矩阵，但每个性状有独立均值系数；联合残差允许骨段相关。外测跗跖参与联合似然及参考条件更新，不得把目标外测跗跖当作预测目标骨长时的已知协变量。

## 评价与不确定性

主读数沿用两个骨比坐标的联合RMSE。在相同的完整三骨实测物种上，先在物种内平均重复窗口平方误差，再在科内平均，最后科等权平均开平方。神经网络先平均两训练种子的科级MSE，非先集成预测。骨长和总长用log10尺度，比例为log10比值；不按厘米解释。

同时报告三段骨长、总长、跗跖/股骨比例和外测跗跖。外测使用其全部实测支持，其余读数使用共同完整三骨支持。由四个预测原始长度按同一公式推导总长及比例，不给某个基线单独拟合这些答案。

保留已保存Ridge和五个神经网络配置，不用新基线替换或抹掉旧结果。两个主要差值为BM−完整EvoWM及OU−完整EvoWM的联合比例RMSE；按科配对重抽样，输出95%区间，并为两项主要比较输出Bonferroni口径97.5%区间。其它读数和架构比较为描述性区间，不挑选最有利读数替代主读数。固定已训练模型的科重抽样不包含重新训练或换树不确定性。

纯均值与近亲条件修正的区别、误差分解及优化边界完整保留。AIC只描述经典模型内部拟合，不与神经网络比较AIC。若OU的alpha收缩到BM边界，应报告这一结果，而不强迫两模型产生差异。

数值搜索预先限定alpha在0至50（完整树高度归一化单位）、eta在0至10；正值网格下限分别为1e-7和1e-8，并独立检查精确零边界。保留边界profile、有限网格及三个联合起点，选定解必须由成功优化终点在似然容差内认证，或有成功相邻profile支持的明确边界认证。否则从最佳候选再进行一次有界局部refinement，仍无认证则报错并保存诊断。若达到搜索上界，必须在报告中显示；该结果只表示有界拟合，不声称已找到无约束全局最优。

## 验证与执行要求

数值实现必须与小树显式协方差矩阵的GLS、联合高斯似然及条件均值/协方差核对；包括固定根OU的alpha→0、部分缺失参考、无目标输入、树顺序和尺度。数据检查必须证明训练/测试分离、窗口一致、目标不在参考集合、50份保存预测支持匹配。拟合不收敛、源哈希改变、目标泄漏和不可识别设计应报错。

新增运行独立保存至`outputs/allen_phylo_baselines_v1_*`，冻结代码与配置、保存拟合参数和所有窗口预测，并自动生成轻量审阅包。无需神经网络checkpoint和GPU。`--smoke`使用主fold的真实全训练样本；`--full`使用五fold；支持恢复已完成任务，运行资源按CPU并行配置。具体命令见下节，验证结果另存results文档，避免修改已冻结设计。

## 运行命令

服务器在EvoWM根目录、已有evowm环境中执行：

```bash
cd /mnt/zihanw/EvoWM
SOURCE_RUN="outputs/allen_overnight_v3_20261110_150810_454903"
WORKERS=1 THREADS_PER_JOB=2 bash scripts/allen_world/run_phylo_baselines_v1.sh --source-run "$SOURCE_RUN" --smoke &&
WORKERS=5 THREADS_PER_JOB=2 bash scripts/allen_world/run_phylo_baselines_v1.sh --source-run "$SOURCE_RUN" --full
```

五个fold为五个独立任务，所以默认五进程、每进程两条数值计算线程；增加至64个进程不会带来额外任务并行。全过程CPU计算，无需占用A100。可先加`--check-only`仅冻结并检查输入，再使用下述resume执行该运行；恢复时沿用该运行的smoke/full配置。

```bash
WORKERS=5 THREADS_PER_JOB=2 bash scripts/allen_world/run_phylo_baselines_v1.sh --resume outputs/allen_phylo_baselines_v1_实际运行时间
```

已完成fold经文件哈希验证后直接保留；失败或未完成fold目录移至该run的attempts，然后重做。源代码或冻结输入改变时会停止，需建立新run。每fold日志位于logs/fold_*.log。结束时打印DOWNLOAD路径，自动生成同名`_review.tar.gz`，包含报告、逐窗口预测、拟合参数、输入和源码快照，不包含旧训练权重。

新增代码验证：

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 NUMEXPR_NUM_THREADS=1 \
python -m unittest discover -s tests -p 'test_allen_phylo_*.py' -v
```

汇总中的n_folds是覆盖的折数，n_training_seeds只数实际训练种子（经典模型为0），n_error_realizations为每折误差实现数（经典模型为1，神经网络为2），n_underlying_fits为所依赖的拟合总数。bm_mean/ou_mean复用各自模型拟合，仅去掉参考残差修正，不是另外训练的模型。
