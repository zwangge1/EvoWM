# Allen 两层解剖尺度 JEPA 架构草案

日期：2026-11-10。状态：讨论方案，尚未实现、运行或锁定超参数。本轮不改训练与评估代码。相关材料：[研究范围](Allen两层解剖尺度预测_讨论稿_2026-11-10.md)、[已完成单层结果](../results/Allen单层过夜实验_核查记录_2026-11-10.md)。

## 理论动机与可检验假说

三段骨长可以表示为整体尺寸与局部分配：S=L_fem+L_tbt+L_tmt，p_i=L_i/S，因而log10(L_i)=log10(S)+log10(p_i)。在同一条件扰动下，骨段响应由整体尺寸响应和比例响应相加构成；两个骨段的log长度响应之差消去共享的log总长项，等于相应log比例响应之差。

这直接连接Allen主线：整体尺寸变化是否足够解释温度关联，还是局部分配也随温度、发育方式和生态背景改变。该分解是代数恒等式，本身不能证明层级模型优于OU、线性模型或单层网络。

候选归纳偏置是：共享整体状态提供协调信息，局部预测保留骨段差异，分别学习可预测表示可能在有限且不完整的形态数据上改善泛化。需要分别验证分层、层间信息传递与JEPA训练目标的贡献。理论不能推出“所有解剖异质性任务必须采用H-JEPA”。

原H-JEPA使用时间跨度不同的表示预测与上层规划目标。本方案保留逐层编码、逐层条件预测、表示匹配和联合训练，改为同一目标物种的解剖尺度；直接将高层预测作为低层预测条件也是本方案的适配，不等同于照搬原论文的规划流程。名称暂用“受H-JEPA启发的两层解剖尺度JEPA”。

## 层级命名与任务

L1为细粒度形态层，L2为整体形态层。编码顺序L1到L2；目标预测顺序L2到L1。两个层次都预测同一个目标物种，不把现生物种窗口当成祖先到后代的时间。

首版保留原三个参考物种的上下文及同一批目标窗口，以便与已有单层比较。目标物种的形态完全隐藏；参考物种的已知形态和目标生态条件可以使用。沿用现有按科留出及上下文可用性口径，不能称为对整科完全无形态资料的预测。

## 输入和标签

形态输入沿用外测跗跖、股骨、胫跗骨、跗跖骨的四个log10长度及四个观测掩码。缺失值经训练集标准化后填零，并保留缺失掩码；填充值不是测量真值。

条件沿用v2的117维条件接口，包含来源与目标生态值、差值、有效性和提供标志及亲缘距离：温度bio1/bio5/bio6、七个觅食层比例、发育方式、体重、运动代理、栖境及迁徙背景。两层可以访问同一组条件，并有自己的条件编码器；不硬性规定温度只进某层、体重只进某层。运动不另设层级。

标签新增三骨总长S、两个独立log比例坐标，以及complete_three_bones。S和比例只由三骨齐全的观测生成。外测跗跖独立读出，不并入S，不作为缺失总长的替代真值。所有归一化与比例中心仅由训练折拟合。

现有资格样本9,172种，完整三骨1,096种。较大的外测样本可参与现有细层和外测监督；高层形态目标匹配及总长、比例监督首版仅使用完整三骨目标，不把插补值当观测。参考上下文允许缺骨，继续使用其掩码。完整骨样本的批次抽样和权重如需调整，全部对照同步调整并记录。

## 自下而上的表示

对物种i，细层表示z1_i=E1(四形态值,四掩码)。E1沿用原形态编码器及当前表示维度。

整体表示z2_i=E2(z1_i)，E2新增小型编码器。整体表示宽度从小规模候选开始，使用训练内部验证选择，不按真实温度梯度的显著性选择。

z2称“以三骨总长读数约束的整体形态表示”，而非“纯总长”。总长读出使它保留整体尺寸信息，但不保证完全排除比例信息；必须报告这一区别。低维也不能单独证明语义抽象成立。

如果高层被严格限定为一个总长标量，应改用标量或极低维整体预测模块，并承认其接近普通回归。不能把单一总长扩为高维后用强SIGReg人为制造丰富状态。当前推荐较丰富整体表示作为候选，并以“只传总长”的对照验证其必要性。

目标物种的z1与z2只在训练目标分支计算，用于误差与防坍塌约束；不作为预测器条件。目标表示不直接拼入目标温度或发育标签，避免以复制已知环境代替学习形态。

## 自上而下的预测

高层预测器F2输入三个参考物种的z2、同一条件信息及亲缘距离，输出目标整体预测z2_hat。总长读出D_S(z2_hat)给出s_hat=log10(S_hat)。

低层预测器F1输入三个参考物种的z1、同一条件信息，以及预测的z2_hat与s_hat，输出目标细层预测z1_hat。实现可复用原Transformer预测器，并以显式条件适配模块引入高层预测；接口必须能独立关闭该信息通路。

比例读出D_p(z1_hat)输出两个自由logit，第三个固定为零，经softmax得到三个正比例且和为一。最终log10(L_hat_i)=s_hat+log10(p_hat_i)。外测跗跖由z1_hat另行读出。

训练与推理均使用预测的z2_hat和s_hat，不以实测总长进行teacher forcing。上层预测错误可能传递到下层，这是要测量的性能代价，不能隐藏。不得对温度斜率、骨段排序、股骨零响应设置硬约束。

## 训练目标

训练目标分为四组：

1. 细层JEPA表示预测误差及与其匹配的防坍塌项，保留原实现的基本机制。
2. 整体层JEPA表示预测误差及低维整体表示的防坍塌项，仅在有有效完整三骨目标时计算相应高层目标项。
3. 原四形态的有效观测误差，按训练尺度和实际观测掩码处理。
4. 完整三骨上的log总长和两个独立比例坐标误差，使整体与分配读数可解释。

总长、比例、三骨长度并非独立数据，组合损失属于对同一形态信息的重加权。必须给单层及普通监督对照相同的观测监督项，避免把额外标签形式或损失权重误认成层级增益。损失权重在训练内部确定、锁定后评估；不依据想要的温度排序调权重。

训练与评估共用同一前向预测路径。原SIGReg、残差预测和优化器接口尽量复用；不同时引入EMA、不同分折或新的训练数据来源等无关变动。

## 从现有单层迁移

| 模块 | 保留 | 新增或调整 |
|---|---|---|
| AllenDataset | 形态输入、条件组、参考窗口、缺失掩码和分组遮蔽 | 总长与比例标签、完整三骨目标掩码；读取已保存冻结分折 |
| 上游JEPA组件 | 编码器、条件编码器、预测器构建与正则工具 | 在鸟类适配器中组合第二层，不使用原时间分块或现有clade units |
| 低层模型 | 现有状态表示和预测器作为基线及初始化来源 | 可关闭的高层预测条件入口 |
| 输出模块 | 外测跗跖独立输出、总长与比例重构的数值实现 | 总长改由高层预测读出，比例由受高层条件影响的低层读出 |
| 前向训练 | 训练集归一化、实际目标掩码 | 两层分别编码与预测、明确目标分支及联合损失 |
| 评估 | 留出窗口、按物种后按科汇总、温度读数和模拟真值配对 | 输出整体与比例响应、层间对照及两个层次诊断 |

现有`allen_readout.create_world_model`明确要求num_levels=1，现有`allen_forward`也是单层包装；不能只改配置层数。新增opt-in适配器，保留v2代码与配置。现有units按类群聚合且窗口独立采样，不适合这里两个层次对应同一目标物种的任务。

工程检查可以载入旧单层参数验证一致性，但正式两层与对照需一致初始化策略、训练预算和模型选择过程。旧检查点不作为额外预训练优势只提供给两层。旧服务器冻结分折与本地重算不同，首版须以保存映射为准并校验。

## 第二层作用的直接检验

| 对照 | 保持一致的部分 | 被检验的作用 |
|---|---|---|
| 单层且容量尽量匹配 | 相同输入、总长/比例/骨长监督、数据及训练预算 | 增益是否超出参数量与重表达输出 |
| 两层但断开整体到比例预测的条件连接，重新训练 | 两层编码、各层损失、高层S输出，以及最终S×p重构均保留 | 整体信息是否真正帮助局部分配，而非仅有辅助监督 |
| 仅向细层传预测总长，隐藏其余整体表示，重新训练 | 高层模型及总长预测、相同骨段输出 | 丰富整体表示是否超出一个总长数值的作用 |
| 同两层骨干的普通监督版本 | 信息路径、观测监督、近似容量与训练预算 | 两层JEPA表示学习方案是否超出普通分层监督模型 |

不把测试时随机打乱高层表示作为主要证据，因为可能制造训练时未见的输入组合。正则及参数调整需明确记录；纯监督对照去除JEPA表示目标及其配套防坍塌目标，故该比较归因于JEPA训练方案整体，而不是单独某一个正则项。

OU与Ridge是外部预测基线，必须获得合理且匹配的信息，OU允许各骨段有不同响应。OU融合残差方案放在上述层级机制检验之后，避免同轮引入OU与层级而无法定位收益。

## 评价与判读

正式选择规则需在运行前锁定。评价包含完整三骨上的各骨长误差、两个独立log比例坐标的联合误差和总长误差；外测跗跖另报。完整模型与断连接版本的比例误差差异，是层间信息帮助局部分配的直接读数。

骨段温度响应、两个相邻响应差及零效应检查在已知答案模拟中评分。模拟包含共享总量、骨段分配受条件调节、不同但简单线性响应、零效应、反向梯度及无共享结构的情景；不要求复杂模型在全部简单情景都胜出，也不因某情景不利而删除。

真实温度分析同时保留年均温单独扰动与三温度共同推移，报告两者的含义和支持范围。已有v2结果已参与设计，后续使用锁定的评估协议并说明开发历史；有条件时用核查重叠后的外部数据检验迁移。

使用多个训练种子、按科配对比较及效应大小，不把窗口当独立物种，也不只依据p值判断实质收益。首次开发可采用统一主树；声称对系统发育假设稳健需另做换树检查。

若两层优于单层但断连接后不变，支持辅助监督或额外表示的作用，尚不支持高层指导局部。若只传总长与完整表示一样好，更简单的整体条件模型已足够。若同结构纯监督也一样好，不能将收益归因于JEPA。只有对应比较成立，才分别提出相应方法主张。
